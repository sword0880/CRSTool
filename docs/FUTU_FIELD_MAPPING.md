# 富途字段映射与规范化输入

更新日期：2026-10-10。依据当前 FutuImporter、FutuTradeExcelImporter 与 FutuDividendExcelImporter。支持布局和限制见 [导入指南](FUTU_CSHARP_IMPORT_GUIDE.md)；[原字段提案](archive/FUTU_FIELD_MAPPING.md)仅作历史参考。

## 收入主表

| 来源字段 | 规范化事实 | 校验 |
| --- | --- | --- |
| 年份／Year | AnnualIncome.Year | 整数年度，与选择年度一致 |
| 账户名称／Account | AccountName，绑定可靠账户身份 | 不能为空；不能唯一绑定交易账户时提示 |
| 全年股息／Dividends | Dividend | 十进制金额 |
| 全年利息／Interest | Interest | 十进制金额 |
| 全年其他收入／Other income | OtherIncome | 保留并复核，不自行并入已支持税目 |
| 币种或带币种的金额字段 | Currency | 全行币种一致，纯利息行也检查 |

同账户、年度、币种收入主数据不能重复累加。年度主表是收入来源，资金进出中的派息明细仅用于核对和展示，不能再计一份收入。PDF 只支持已验证的文本布局，扫描件与未知表头拒绝。

## 交易工作簿

账户信息要求年份、账户号码、账户名称。交易流水要求成交时间、品类、代码名称、方向、数量/面值、价格、币种、账户号码、交易所/市场。

| 来源字段 | 规范化事实 | 行为 |
| --- | --- | --- |
| 成交时间 | Trade.Time / HasOffset | 保留时间和时区语义 |
| 账户号码、代码名称、市场、币种 | SecurityKey | 完整身份隔离 |
| 方向、数量/面值 | Side / Quantity | 校验方向及符号后取规范化数量 |
| 成交金额、价格 | Gross / Price | 券商总额优先；核对数量乘价格 |
| 总费用 | Fee | 缺失生成成本问题，不当作已确认零费用 |
| 变动金额 | Net | 保留净现金并核对金额 |
| 文件、工作表、行序 | 来源及生成 ID | 缺稳定成交 ID 时，重叠主报告拒绝自动去重 |

列顺序可变，公式和错误单元格拒绝。具体中文／英文表头别名以解析器源码为准，不能仅凭文件扩展名宣称任意布局受支持。

## 持仓与事件

持仓总览用于期初／期末数量核对，价格是市价，不初始化真实 LOT 成本。资产进出进入 SecurityMovement 并保留未知事件；同日 In/Out 不足以自动合并更名或建立赠股零成本。

资金进出保留原币、金额方向、类型和来源；扣税退回与净退税继续校验。资金总览用于现金核对，缺失资料保留无法核对状态。

当前 C# 源码与验证入口已独立运行，不依赖 Python；迁移前的本地参考事实只能作为历史对照，不能当成唯一正确金额。
