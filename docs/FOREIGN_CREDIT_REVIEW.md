# 境外税额抵免复核

在历史任务选中账户任务或年度汇总，点击“导入抵免明细”。成功后生成保留父任务编号的新任务；原任务不改写。税务页及 Excel 增加国家限额、所得分配与凭证关系三张表。

模板为 [抵免明细](../tests/templates/foreign-credit.example.json)。示例金额、账户、机关和文件均为占位值，必须替换。凭证路径可相对明细文件目录填写。当前入口是 JSON 文件导入，尚无逐行编辑表单。

## 明细约束

- `Income` 必须完整分配各券商、账户、币种的原币股息与利息，严格等于已导入事实；不能按交易币种推定所得来源国家。`Country` 为两位大写国家／地区代码，正确来源地仍需人工核对；`Category` 只支持 `Dividend`、`Interest`。
- `Payments` 登记实际税款、征税机关、唯一凭证编号、国家和所得项目。每个账户同币种税款合计不能超过导入净预扣税；未提供凭证的差额不参与本次抵免。
- `Proofs` 提供 `TaxReceipt`，或同时提供 `DeclarationOrNotice` 与 `Payment`。程序只验证原件存在、大小、关联关系和摘要，不能验证文件真实性或税务机关认可程度。
- `Exclusion` 留空表示进入辅助限额测算；`Refunded`、`Penalty`、`TreatyDisallowed`、`WronglyLevied`、`Exempt` 均排除。人工必须识别具体排除原因，不能仅靠空字符串推定合法税款。
- 明细限 1 MB、每笔最多 10 份凭证、单份凭证非空且不超过 25 MB。同一凭证不能通过换编号重复登记；共用一张凭证覆盖多个所得项目、负收入、净退税、跨年缴税或境外非日历纳税年度暂需单独复核，入口明确不自动处理。

## 辅助计算与冻结

按国家合并本项目支持的股息与利息，使用该任务冻结汇率、20% 辅助算法计算限额，逐国取可登记税款与限额较小值。其他国家的收入不增加本国抵免限额，超限单独披露，不自动生成五年结转记录。证券转让抵免、综合所得／经营所得限额和协定适用判断尚未接入。

凭证名称、SHA256、税款编号及所得分配冻结在结果和底稿中；凭证正文和绝对路径不写入结果。完整来源数据仍具有账户信息，不能称为匿名数据。年度汇总导入的明细需覆盖全部来源账户，不能把来源任务已限额的抵免金额直接相加。

新导入发现预扣税时增加 `TAX_CREDIT_UNVERIFIED`，关闭预计补税。结构化复核后按国家抵免替换辅助公式值，但保留 `TAX_CREDIT_REVIEW`，预计补税仍为空；原件真实性、法定外币折算、所得来源与协定资格必须独立核实。凭证复核派生任务目前只能查看和导出，不支持沿用旧规范化快照等价重放。

## 规则依据与适用边界

已核对[财政部、税务总局公告 2020 年第 3 号](https://shanghai.chinatax.gov.cn/zcfw/zcfgk/grsds/202002/t452398.html)：个人境外所得按国家／地区计算限额；实际缴纳、可抵免税款存在排除条件；有缴税证明要求；超限结转及非日历纳税年度另有规则。公告要求的法定汇率折算并不等同于本项目目前使用的年度平均辅助汇率。因此，本次功能为可追溯的复核与辅助计算入口，不代表申报资格和金额验收已经完成。
