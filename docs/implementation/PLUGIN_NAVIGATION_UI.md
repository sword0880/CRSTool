# 插件导航与管理界面整改（2026-10-15）

## 页面互斥与侧栏折叠

原扩展内容层只在打开页面时写入206/56像素的左偏移。打开插件后收起侧栏，内容层仍保留206像素偏移，底下未隐藏的历史页随导航收窄，形成两个页面同时显示。

扩展内容层现通过绑定实时跟随侧栏状态；扩展页打开时隐藏内置导航内容容器但保留布局，返回内置页时清空扩展内容并恢复容器。任务中心、服务状态、插件页面和插件管理共用该入口。任务中心先显示页面再刷新状态，避免刷新结束后覆盖用户后来打开的页面。

## 插件管理表格

管理页新增运行中、已禁用、异常的状态概览和运行比例条；表格显示插件图标、名称、标识、版本、当前状态、下次启动设置及图标操作。版本由宿主已核验并选中的清单提供，不按目录中最大版本猜测；未核验或版本无法确定时明确显示未确定。

暂停图标表示下次启动禁用，播放图标表示下次启动启用；悬停提示与无障碍名称说明具体动作。保存后显示待生效提示，允许再次切换撤回设置；不改变本次运行状态。配置写入成功后才更新宿主内存设置；失败时显示保存失败，重新打开页面也不显示虚假成功。

## 验证

插件管理表格保留高对比度选中行、键盘焦点和状态标签语义色。2026-10-20起，页面主色和交互底色已改为[全局品牌主题](BRAND_VISUAL_SYSTEM.md)；此处不再维护独立的蓝色视觉规则。
