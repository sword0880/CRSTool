# 直接持股以股票清单为入口

日期：2026-11-01。

## 行为

“资金与持仓 → 机构直接持股”默认进入“股票清单”：相同市场与代码只显示一行，只列代码、股票、持有机构、账户数、报告期五列。点击股票后只显示持有人/账户、股数、原披露占总股本比例、报告期和原文链接五列，便于大致查看持仓分布。

首页只保留搜索、机构筛选和刷新。股票×机构矩阵、持仓方向、历史补入、观察配置、性质及其他披露筛选收进“高级工具”；单个账户的图表、历次变动及人工核验收进“更多详情”。默认不查询图表、历史或核验资料，主动打开更多详情后才读取；关闭恢复持有人页。

默认“已核验持股”仅包含证据等级为已披露持仓、机构类别已确认且持股数为正的快照。“高级工具”中的“其他披露 / 待核验”保留未列示、待核验、冲突、异常及不满足正式清单门槛的记录；两类可包含同一股票，候选不会挤掉已有已核验快照。空清单显示入口说明，查询失败明确报错。

顶部搜索、机构、性质及关注筛选继续由后台执行。清单及账户数仅代表当前筛选范围，不代表完整国家队组合；观察目录不自动成为持股事实。机构类别数不等于独立法人总数，同一机构下的组合逐账户显示。多个报告期显示范围，不合计股数，不把未列示或零股数推断为清仓。

未选股票时清单占满内容区，点击后才展开下方详情。股票切换回到持有人页，刷新保留仍存在的股票与账户。清空筛选结果、范围切换无匹配股票及读取失败时清除旧详情，并作废迟到的旧股票请求。股票×机构总览仍可跳转到股票及相应证据范围。

## 分层

- Core 的 `Domain/Equity/EquityStockList.cs` 负责证据门槛及按市场、代码分组，保留原逐账户事实，不推算持仓变化。
- Watch 的 `Presentation/Equity/EquityViewModel.Stocks.cs` 负责列表、选择和详情联动；WPF 不访问数据库，不下载公告，不写入持仓事实。
- 复用既有 Worker 查询、原文核验及关注命令，无数据库结构或通信协议变化。

本记录替代[初版设计](DIRECT_EQUITY_TRACKING_DESIGN_20261018.md)的默认账户列表入口；图表、矩阵及原有证据约束继续见[图表与总览](EQUITY_CHARTS_20261019.md)。
