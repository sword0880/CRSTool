# 国家队及长期资金直接持股跟踪方案

2026-10-18。用户已同意ETF可靠性与趋势改进方向，并要求增加直接持股跟踪；随后明确将机构范围扩大到社保和养老金。

## 交付状态

本文件及交互样图落实展示和判定规则，不代表已增加生产股票持仓、已接通官方自动采集或已完成上一轮ETF问题修复。样图中的股票、数值、报告日期和变动事件全部为虚构演示，不进入实际市场数据库。

## 机构范围

- 核心政策性资金观察：中央汇金投资、中央汇金资产管理、中国证券金融。
- 长期资金观察：全国社保基金的具体组合、基本养老保险基金的具体组合，按官方原文账户名称独立登记。
- 集团关系可汇总展示，但保留法律主体和组合身份；不能将受托管理人同时当成持有人重复计数。汇金控股的机构也不能自动纳入汇金直接持股。
- 一般地方国资、央企战略股东、北向资金不自动纳入。
- “战略控股/参股”作为持仓性质单独分组；不与普通证券投资持仓混算短期交易趋势。

## 日常使用

在现有“国家队观察”插件新增“直接持股”入口，ETF份额和直接持股共享证据基础设施，保持独立事实与图表。

主页面使用持仓工作台：

1. 顶部常驻搜索、机构/组合、持仓性质、披露状态、报告期以及“仅关注”筛选。刷新保留条件和选中股票。
2. 默认表格一行一个“具体持有人×证券市场×代码×股类×持仓口径”，优先显示持仓变化、报告截止日、公告日和证据状态。按股票汇总是可选视图，不丢失机构明细。
3. 点击股票展示详情：相关机构、最近可核验持仓、各报告期持仓点、增减持公告、证据原文。持仓图只画离散披露点，不在两个报告期之间补每日持仓，也不前向填充为已确认持仓。
4. 同一股票的股价和成交额使用每日行情；标记信息实际公告日期，不将报告期末当作市场当时已知日期。行情日期、更新时间和来源独立标明。没有行情时显示不可用，不编造价格走势。
5. “变动事件”按首次披露日降序展示。新增已确认披露、持股变化、原文更正、证据异常可作为页内待查看事件；单纯每日重新抓到同一报告不新增事件。跨期缺失另列数据质量事件。
6. 支持关注股票和具体机构组合。自动通知、跨设备同步不在本次样图交付中，不能把样图点击状态称为生产配置保存。

首屏表格优先列：股票、持有人、持股数、可比股数变化、持仓截止日、公告日、状态。持股比例及分母、股类、来源和行情详情可在展开区展示；不把所有字段挤入首屏。

## 变动语义

| 条件 | 展示 | 禁止推断 |
|---|---|---|
| 两个报告时点同主体/同证券/同股类/同口径，股本事件已处理 | 确认净增持/净减持/持平 | 不能给出期间内具体每日交易或成交价 |
| 当前出现、前一期股东榜未列示 | 首次列示，前值未知 | 不等于首次买入，不能用0作前值 |
| 上一期出现、本期股东榜未列示 | 本期未列示，当前持仓未知 | 不等于清仓或确认减持 |
| 官方明确数量为0或有完整退出证据 | 对具体主体、具体证券标记已退出，附依据 | 不推断该主体退出其他股票或整个市场 |
| 仅持股比例降低、持股数不变 | 股数持平，比例下降 | 不当作卖出 |
| 送转、配股、A/H切换、限售/流通口径或主体关系未核验 | 不可比，待核验 | 不直接算增减持或资金流 |
| 官方增减持公告只披露某段交易量 | 单独行为事件，保留交易区间 | 不加到不匹配时点的持仓快照，避免重复计算 |

每次状态判断都保留比较基准报告、算法版本和证据链。对“不在前十大”只能记录未列示；如官方明示门槛，可展示上界信息，不能猜精确持仓。

## 数据与架构

官方上市公司年报/中报/季报、权益变动及增减持公告作为原文事实。交易所结构化股东数据用于发现候选和辅助提取，以正式PDF核验；不能将网站的“数据日期”未经核验直接作为报告截止日。

建议的服务端实体：

- `Institution`、`InstitutionAccount`、`ReviewedAlias`：法律主体、组合账号与已审核别名；不能模糊匹配“汇金”“社保”就自动确认身份。
- `DisclosureRevision`：官方URL、原件哈希、公告时间、首次发现时间、修订关系、提取及审核状态。
- `HoldingSnapshot`：市场/代码/股类、持有人及组合、报告截止日、股数、比例及分母、持仓性质、榜单类型、披露范围、原文页码、证据版本。
- `HoldingPresence`：已披露具体股数/明确零/完整榜单中未列示/来源缺失等状态，不能用一个null代表所有情况。
- `HoldingChangeEvent`：公告事件或可比时点推导事件，记录依据、比较前后版本、公司行为可比性。
- `EquityWatchlist`、`DisclosureScanCursor`：股票/机构观察配置、增量检查进度和缺口，不能因来源失败跳过未完成文档。

所有下载、解析、审核、持久写入、快照比较和指标判定在Worker/Core执行；WPF只显示服务端DTO并提交命令。查询先在服务端过滤，再沿用分页快照。新增表应使用明确版本迁移及恢复测试，不默认清空现有ETF库。

自动获取尚需核验官方通道、限速、完整分页和历史范围；公开网页可读不等于已经有可靠的全市场结构化扫描接口。PDF提取只能形成候选，无法确认页码、表头、单位、股类和主体时保留待审核，不能写入已确认持仓。

## 与趋势判断的关系

持股披露用于回答“某主体在两个报告时点之间是否净减持”，ETF申赎用于观察基金份额压力，行情量价用于趋势观察。三者可并列查看，但不合成未经验证的“国家队退出概率”。社保和养老的配置周期与政策性资金不同，信号先分组再研究。

回测只使用当时已公布的版本，按公告日进入信息集；保留旧版本避免事后更正污染历史。不能以新增股票今日的持仓名单反选过去样本而忽略退出标的。

## 必须验证

- 汇金投资/资管主体分离，社保/养老各组合独立，别名及管理人不会重复计数。
- 两期未列示、首次列示、明确0、漏采、未审核和冲突的区别。
- 比例下降但股数不变、拆股/送转、股份类别或分母变化、公告与报告时点不一致。
- 同报告重抓幂等、更正报告重算、旧证据仍可追溯、损坏与修复闭环。
- 股东榜类型不能重复累加；前十大股东与前十大流通股东可有重叠。
- 筛选在分页前执行；刷新保留阅读位置；切换股票不会显示旧结果；空结果清除旧详情。
- UI主操作首屏可见、键盘可访问；无来源或无行情明确空状态。
