# 南向年度累计净买入

<a id="southbound-annual-comparison"></a>
<a id="southbound-net-sell-visibility"></a>
<a id="southbound-unknown-query-fix"></a>

桌面“国家队研究 → 资金与持仓 → 南向累计净买入”比较不同年度的年内累计净买入。指标为港股通沪、深两路每日买入减卖出之和，每年重新累计，单位亿港元；不混用额度净流入、整个港股市场资金流或具名机构成交。

## 唯一年度图

默认选择最近五年，可在最近十年内开关年份，最早2017年。仅一张年度累计折线，通过滚轮缩放、拖动、框选查看短期及单日；横轴使用统一闰年月日坐标，普通年3月以后不偏移。没有独立单日图，也不增加柱图、指数或成交额面积图。

曲线下降表示当日净卖出，即使年内累计仍为正。悬停直接读取后台当日净额和累计额，同时显示真实日期及两种口径，不由累计反推当日金额。缺累计基准明确不可用，不能用当日金额代替累计。

全年金额范围包括零和实际负值；放大允许离开零点，短于两个月改用自动日刻度，最小横轴范围一天，金额轴允许0.0001亿港元的显示跨度。“重置缩放”、刷新或切换年份恢复全年月刻度及零基准。空态隐藏画面并保留画布布局，不显示默认零金额坐标。

只显示实际可计算的观察点，不补造周末、休市日、未来日或年初零点。缩放仅改变视口，不改变金额和采集范围。重新查询清除旧图，取消后晚到响应不能覆盖当前结果。

## 金额与连续性

`当日净买入 = 沪路(买入−卖出) + 深路(买入−卖出)`。来源百万港元除以100转换为亿港元。买卖额齐备时直接相减，并与来源净买额核对；缺少买卖额但明确公布净额时采用原字段，不把空值当零。

来源历史累计额只用于连续性核对，不直接作为年内曲线。每年需上一年最后同日、两路齐备的累计额作基准，逐日检查“当前历史累计−前次历史累计＝当日净额”，逐项仅容忍0.02百万港元的舍入尾差。

跨年基准缺失、任一路必要净额/累计字段缺失或累计跳变时，该年度自断点起不可计算；不跳缺口继续累计，不连接后续错误金额。相邻年度用各自年末基准独立计算。没有独立交易日历分母，不声称完整预期交易日覆盖。

2025-02-04的历史样本买卖额为空，但两路明确公布净额0且累计不变，可保留该来源公布的零；这不是补零，也不据此推断交易日状态。

## 来源、后台与协议

来源为[东方财富沪深港通](https://data.eastmoney.com/hsgt/hsgtV2.html)公开报表`RPT_MUTUAL_DEAL_HISTORY`，只允许通道002/004及`MUTUAL_TYPE / TRADE_DATE / BUY_AMT / SELL_AMT / NET_DEAL_AMT / ACCUM_DEAL_AMT`。不读取`FUND_INFLOW`或额度余额，不拼接交易所历史人民币金额。页面明确说明第三方整理来源。

历史从2016-12-01读取，为2017年提供基准；每页2000行、最多5页/10000行。分页、日期、金额、唯一性、排序与净额关系全部通过才登记，任一失败不提交部分快照。原件逐字节保存，独立只读查询重新核验；损坏或格式不符明确不可用。

| 模块 | 所有权 |

| Core的Southbound Domain/Application | 口径、逐年重置、连续性及窄端口 |

独立查询操作`southbound-net-annual`，`FormatVersion=2 / Metric=YearToDateNetBuyTurnover`；不能回退到旧每日买入查询冒充兼容。旧买入快照保留，累计版本使用追加式`nt_southbound_net_capture / nt_southbound_net_command`及版本化清单，根格式仍为2；不将旧原件补造卖出字段。

后台计划`southbound-sync`、管理操作`southbound-net-sync`，默认北京时间23:40，沿用collection=2执行组及独立来源串行预算。`EASTMONEY-SOUTHBOUND`与交易所、基金来源分别限速及持久退避，固定地址、拒绝重定向，不绕过403/429。旧宿主不支持新预算时拒绝本功能更新，需配套更新Worker与插件。

查询超时不停止已受理采集；受理未知沿原ID核查。客户端把本查询的`UnknownQuery`映射为需要更新后台的版本提示，不返回空曲线。查询与管理捕获`InvalidDataException`，包括真实Loaded首次读取；失败清理Busy及旧报告，未知回执不误报成功。
