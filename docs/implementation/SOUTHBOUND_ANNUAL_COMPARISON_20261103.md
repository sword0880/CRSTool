# 南向买入年度折线（2026-11-03）

用户要求将不同年度放在同一张折线图内相互比较，仅保留折线展示。本功能采用最初需求的**每日买入成交金额**，不擅自替换为净买入、年内累计或资金流预测。

## 界面

国家队研究工作台 → 资金与持仓 → 南向买入年度对比。默认勾选最近五年，可在最近十个年度内分别开关年份；最早为2017年。横轴为月日，纵轴为亿港元，一年一条折线，不增加柱图、面积图、指数对照或数据表。悬停显示观测的真实年份、月日和金额。日期轴使用统一闰年坐标，2月29日单独占位，普通年的3月以后不发生一天错位。

只连接真实有效观测点；休市、缺日及未来日期不填零、不插值、不向后延伸。某日沪深两路任一路缺少记录或金额，合计为不可用；有来源的真实零金额保留。无资料、未选择年份、失败及取消都不显示默认零金额坐标。重新查询先清除旧图，取消后的晚到结果不能覆盖页面。

## 来源与口径

使用[东方财富沪深港通页面](https://data.eastmoney.com/hsgt/index.html)对应的公开历史报表 `RPT_MUTUAL_DEAL_HISTORY`，仅请求 `MUTUAL_TYPE,TRADE_DATE,BUY_AMT` 三个字段，通道限定002（港股通沪）及004（港股通深）。页面脚本对两通道的买入成交额标为港元，原值单位为百万港元；后台同日两路金额相加后除以100，得到亿港元。明确显示为第三方整理数据，不冒充交易所直供数据，也不与ETF份额、机构持仓证据或净买入混同。

2026-11-03对2026-11-02样本交叉核对：[港交所原始日统计](https://www.hkex.com.hk/eng/csm/DailyStat/data_tab_daily_20261102e.js)沪路22,520.93百万港元、深路12,803.70百万港元，合计353.2463亿港元，与第三方同日记录一致。这是样本核对，不是所有历史交易日逐项核验。上交所页面另有2024-08-19前后币种切换说明，因此不拼接上交所旧人民币金额。

## 后台边界

`Core/{Domain,Application}/Southbound` 拥有金额合计、月日对齐及窄端口；`Jobs/{Application,Infrastructure,Background}/Southbound` 拥有采集、解析、快照登记和公开只读查询；`NationalTeamWatch/{Application/Worker,Presentation}/Southbound` 只做IPC及展示。WPF不联网、写库或计算金额。

后台任务 `southbound-sync` 默认北京时间23:40更新，支持管理员手动更新。历史从2017-01-01取得；每页2000行、最多5页/10000行。逐页检查成功状态、总数、完整页数、唯一通道日期、范围、金额及排序，任一失败均不提交部分快照。原件内容寻址存证、快照清单摘要及持久命令回执同事务登记，读查询通过独立只读连接重新核对原件并重建年度曲线；缺失或损坏不返回伪造空结果。采集失败保留上一份完整快照，页面显示取得时间和资料截止日期。查询超时不停止已经受理的后台采集，受理未知时沿原请求身份核查。

新增宿主共享来源预算 `EASTMONEY-SOUTHBOUND`，与交易所及基金来源分别串行、限速和持久退避。只放行固定域名、路径、三字段及限定日期/分页参数；不跟随重定向，不绕过403/429。旧宿主不支持该预算时拒绝南向更新，不影响旧功能启动；正式使用需同时更新Worker宿主和后台插件。

新增 `nt_southbound_capture`、`nt_southbound_command` 两表，根格式仍为2。没有修改税务、FIFO、汇率规则或Worker默认总并发。
