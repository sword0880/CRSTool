# 南向年内累计净买入年度折线（2026-11-03）

用户明确选择**年内累计净买入金额**，将不同年度放在同一张折线图内比较。当前指标为每日沪深港股通买入减卖出之和，从每年年初重新累计；允许负值，不混用额度净流入或买入成交额。

## 界面

国家队研究工作台 → 资金与持仓 → 南向累计净买入。默认勾选最近五年，可在最近十年内分别开关年份，最早2017年。每年一条折线，横轴统一月日，纵轴亿港元，悬停显示真实日期和年内累计金额。采用统一闰年坐标，普通年3月以后不偏移；不新增柱图、面积图、指数或表格。

只显示真实可计算的观测点，不补造周末、节假日或未来日期。每年从零起算，但不人为插入休市日零点。负累计额原样显示，纵轴纳入零和负值；无资料、未选年份、失败及取消不显示默认零金额坐标。重新查询清除旧图，取消后晚到的响应不能覆盖当前状态。

## 净买入与连续性

当日净买入＝港股通沪（买入−卖出）＋港股通深（买入−卖出）；年内累计为当年逐日净买入之和，除以100把来源的百万港元转为亿港元。买卖额齐备时直接相减，并与公布净买额核对；买卖额不齐但来源明确公布净买额时采用该原始字段，不从空买卖额推导零。

来源的历史累计净买额只用于核对，不直接作为年内曲线：每年需要上一年最后一条同日期、两通道齐备的累计额作基准，并逐日核对“当前历史累计−前次历史累计＝当日净买入”。这样可以发现年初或中间被源站漏掉的有金额记录。两位小数的来源金额只容忍0.02百万港元的逐项舍入/传输尾差。

缺少跨年基准、任一路净额/累计核对字段缺失，或累计跳变时，该年度从断点起保持不可计算，不跳过缺口继续累计，也不连接后续错误金额。相邻年度用各自原始年末基准独立计算。没有独立交易日历分母，不声称完整覆盖所有预期交易日。

已核对2025-02-04：原件买卖额为空，但两通道均明确公布净买额0，历史累计额也未改变，因此可保留该来源公布的零净额并继续累计；这不是对空值补零，也不据此判断交易日状态。

## 来源与后台

使用[东方财富沪深港通](https://data.eastmoney.com/hsgt/hsgtV2.html)对应的公开报表 RPT_MUTUAL_DEAL_HISTORY，通道只允许002、004，字段只允许 MUTUAL_TYPE、TRADE_DATE、BUY_AMT、SELL_AMT、NET_DEAL_AMT、ACCUM_DEAL_AMT。不读取FUND_INFLOW或额度余额，不拼接上交所历史人民币金额。页面明确标为第三方整理数据，不能代表整个港股资金流或具名机构交易。

历史从2016-12-01读取，为2017年提供年末基准；每页2000行，最多5页/10000行。2026-11-03公开样本共4552条、3页，历史累计的逐条差值核对无断点；这仍是来源内部一致性，不能冒充所有日期与交易所原件逐项核验。2026-11-02沪路净买额−2837.48百万港元、深路−1631.75百万港元，与该日买入减卖出一致；该日合计−44.6923亿港元。

Core的Domain/Application下Southbound模块拥有口径、逐年重置、连续性及窄端口；Jobs的Application/Infrastructure/Background下Southbound模块拥有采集、解析、存证及查询；NationalTeamWatch的Application/Worker和Presentation下Southbound模块只做IPC和展示。WPF不联网、写库或计算金融金额。

查询使用独立操作southbound-net-annual，报告FormatVersion=2、Metric=YearToDateNetBuyTurnover；旧每日买入查询不能冒充兼容。旧的仅买入快照保留，累计版本使用追加式nt_southbound_net_capture、nt_southbound_net_command两表及版本化清单；根格式仍为2。没有将旧版原件补成包含卖出/净买额的资料。

后台任务southbound-sync的管理操作为southbound-net-sync，默认北京时间23:40更新，保留collection=2的宿主执行组约定和独立来源串行预算。完整分页、日期、金额、买卖与净额关系、唯一性和排序通过后才登记；任一失败不提交部分快照。原件逐字节存证，查询通过独立只读连接重新核对原件，损坏或格式不符时明确不可用。查询超时不停止已受理的采集，受理未知时沿原ID核查。

来源预算EASTMONEY-SOUTHBOUND与交易所、基金分别限速和持久退避，只允许固定地址及字段，不跟随重定向、不绕过403/429。旧宿主不支持该预算时拒绝本功能更新，不影响既有功能启动；正式使用需要同时更新Worker宿主和插件。税务、FIFO、汇率及Worker默认总并发未改。
