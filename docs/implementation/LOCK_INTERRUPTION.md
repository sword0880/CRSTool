# 长备份与恢复中的锁定中断

2026-10-13，反方审查 P0-5 的代码修复。锁定先隐藏工作区／启动安全窗口并取消操作，再等待会话退出；不能先等待正在运行的备份门闩才发出取消。

空闲十分钟、Windows 锁屏／注销／会话断开和休眠／恢复自动触发。锁定后的工作区不会立即重开，停留独立锁定页等待主动解锁，避免关闭手机验证时原锁定流程马上自动进入。计时不随后台任务续期，单调时钟边界及事件分类由 `AutomaticLockChecks` 验证；真实窗口检查锁定页不自动触发解锁、不绑定旧模型，并响应主动解锁。实际 Windows 事件和硬件延迟仍不以合成检查替代。

SQLite 在线备份每步最多复制 128 页，每步检查取消。持续 BUSY／LOCKED 超过 30 秒明确失败；短等待可以被取消提前打断。SQL 完整性扫描注册进度回调；分块加密、读取与数据库摘要计算也检查取消。备份和恢复端口接受可选取消令牌，锁定同时取消操作代次与会话。排队的旧任务不能在后续解锁后复活。

取消、失败不提交备份目标或恢复目录；提交之前再次检查取消。已经跨过原子提交边界的完整文件可能保留，不宣称锁定会撤销已完成提交。暂存数据库一直是 SQLCipher 加密内容；清理范围限组件生成的随机暂存文件／目录。

`LockInterruptionChecks` 在实际原生备份步后设置单次测试暂停，验证锁定在 5 秒测试期限内返回、运行中和排队备份取消、旧仓储拒绝访问、原始历史保留、解锁后可再次备份及预取消恢复无目标目录。探针只对单次内部调用生效，没有全局开关或认证绕过。

这是可控自动场景，5 秒不是所有硬件下的延迟承诺。密钥派生、单次原生扫描和操作系统磁盘 I/O 仍可能延迟到取消检查点；实际 Windows 锁屏、休眠、跨用户／电脑恢复、断电、磁盘满与特殊文件系统演练仍待完成。
