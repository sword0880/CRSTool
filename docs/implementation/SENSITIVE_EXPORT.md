# 敏感导出与诊断保护

2026-10-13。数据库加密不覆盖导出的普通文件。报表页优先推荐独立密码加密归档；普通 Excel、LOT JSON 与解密后的资料均为明文。

## 统一入口

Application 的 `SensitiveDataExportService` 集中编排普通 Excel、LOT 结转、加密归档及归档解密四个入口。`DesktopWorkflow` 委托该服务，文件、目录、NPOI 和密码学操作仍由 Infrastructure／Security 完成。

普通导出和解密恢复必须在本次调用提供 `SensitiveExportConsent`，默认缺省或未确认时拒绝，不能只依赖界面弹窗。该参数是调用方对用户确认的声明，不是密码学凭证，不替代保险库认证；锁定和取消继续关联旧会话，提交还由捕获原会话的适配器检查。汇率指纹与可信结转门槛保留，不修改金额、成本或税额规则。

## 目的地与暂存

后台在读取复核记录和构建文件之前检查目的地。普通明文默认拒绝当前 TEMP／TMP、用户 LocalAppData/Temp、Windows/Temp 及其子目录；大小写、点段、设备路径前缀及 Windows 短名称统一处理。明文目的地的目录重解析点拒绝，不能借链接目录绕过检查。无法核对目录时明确失败，不写文件。

实际报表界面不提供临时目录明文特许；用户应改选可信普通目录或加密归档。隔离的合成验收显式传 `TemporaryLocationConfirmed=true`，仅说明调用方专门确认临时位置，不是全局开关、保存配置或自动放行。

普通导出为了避免失败破坏旧文件，仍在目标同目录生成随机暂存明文，再刷新并原子提交；这是用户授权明文落盘的一部分。取消会清理暂存，不能称为可靠物理擦除。加密归档在有界内存中构建工作簿、结转及证据，磁盘暂存仅含密文。解密恢复经明文确认，在用户选择的父目录中新建文件夹。

检查不承诺防御同用户恶意进程在检查与写入之间替换目录，也不覆盖操作系统页面文件、崩溃转储、SSD 残留或用户主动复制、打印的明文。避免非必要落盘优先于删除后的擦除承诺。

## 公式注入与数值

XLSX 中来自券商或人工资料的文本使用字符串单元格，不调用公式接口、不创建外部链接或执行公式。`=`、`+`、`-`、`@`、制表／换行前缀、全角字符及分隔符组合有回归。文本不统一追加前缀，真实负金额继续使用数值单元格；XML 读取的回车／换行可能按格式规范化。

CSV 导出当前未提供。将来增加时必须按 CSV 字段引用、分隔符和目标表格软件设计独立处理；不能直接沿用 XLSX 字符串类型策略或宣称任意软件中保存重开仍安全。依据见 [OWASP CSV 注入指导](https://community.owasp.org/attacks/CSV_Injection)。

## 日志与诊断

导出操作日志只接收固定类型和结果枚举，不接收账户、路径、金额、密码或业务对象；遵循现有日志开关与等级，不宣称为不可篡改审计。失败类别使用允许清单，任意字符串归为 `UnexpectedException`。启动失败和窗口验收诊断同样仅输出固定类别，不落盘异常正文、堆栈或内部异常。

当前未提供自动诊断包，不新增收集业务库、原件、配置秘密或 dump 的功能。操作系统／第三方崩溃转储与实际发布包隐私仍需专项验收；不能以本轮测试宣称全部泄漏面关闭。依据见 [OWASP 日志指导](https://cheatsheetseries.owasp.org/cheatsheets/Logging_Cheat_Sheet.html#data-to-exclude)。

## 验证

`SensitiveExportPolicyChecks` 验证后台默认拒绝、明确授权、路径检查前置、取消／锁定及固定诊断；`SensitiveExportChecks` 验证真实 XLSX 文本类型、负金额、临时路径、加密归档、解密授权与日志敏感标记不出现。WPF 导出与解密交互检查实际授权参数，并保留密码清理、忙碌、取消和原结果保护。

专项入口：`dotnet run --project tests/CRS.Tests.Infrastructure -c Release -- --sensitive-exports-only`。本轮仍保留独立金额、真实设备恢复和发布审查未通过，见 [当前待办](../KNOWN_ISSUES.md)。
