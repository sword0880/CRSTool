# 国家队后台用例与界面端口分离

日期：2026-10-26。承接[分层重构续项](NATIONAL_TEAM_MODULAR_REFACTOR_20261026.md)中的运行时能力缺口；本次不改变金融规则、来源许可或已安装服务。

## 问题与改造

原后台`EtfWorkspace`实现界面`INationalTeamWorkspace`，通过接口默认方法继承行业/指数远程排队等并不属于后台对象的能力；持股联网审核、预警原文登记的方法直接抛错，通知渠道直接返回空集合。页面需要的客户端合同与后台实际用例混在一起，编译通过不能证明全部能力存在。

当前界面六个功能合同全部改为必需实现，移除默认抛错、按证券在客户端过滤全池证据、忽略发件箱筛选等默认方法。正式客户端仍是`WorkerEtfWorkspace`；它通过授权管道完整实现合同，宿主负责渠道列表、持久排队与授权。后台不再实现这些界面合同，也不保留旧`EtfWorkspace`转发壳。

后台组合根`NationalTeamApplication`只有装配、初始化、进度绑定与释放职责，各功能对象独立持有用例：

| 功能对象 | 归属 |
| --- | --- |
| `EtfUseCases` | ETF同步、配置、份额审核、原件导出、覆盖与验收 |
| `EquityUseCases` | 直接持股观察、披露、报告索引与历史原文登记 |
| `IndustryPeUseCases` | 行业公布PE导入、修订与研究读取 |
| `IndexSeriesUseCases` | 指数价格/估值导入、修订与研究读取 |
| `MarketActivityUseCases` | 全市场成交统计、缺口续采与来源退避进度 |
| `NavUseCases` | NAV原件组导入、修订与知识时点读取 |
| `ExitAlertUseCases` | 预警配置、评价、事件、证据、领取与投递结果提交 |
| `EvidenceUseCases` | 短操作取得核验快照，门槛外读原件，短操作提交结果 |

每个对象经`MarketUseCaseScope`调用类型化仓储端口。ETF将原有三个ETF合同组合为`IEtfRepository`，不取得持股、行业或预警仓储。完整`IMarketRepository`仅存在于后台装配及执行会话内，不作为功能用例的字段或参数。

持股报告检索原是放在`Infrastructure/Equity`中的后台会话partial，现移入`Background/Equity/NationalTeamBackgroundSession.Reports.cs`；其联网、持久回执和RetryDeferred行为保持不变。

## 共享执行会话

`MarketApplicationSession`保留一个写入门槛、独立读取会话发布、读取生命周期门槛和关闭顺序。初始化校验仓储必需能力并真实打开只读快照，失败释放连接；重复初始化拒绝，不替换已打开的仓储。取消初始化不创建替代内存或临时资料库。

读取必须经独立快照，不为旧测试适配器回退到写会话；读取等待及取消不会传播到并行采集。关闭等待在途读取和短写入，后续任何功能都拒绝新读写。下载仍在写门槛之外，既有事务、稳定命令标识、知识截止及OutcomeUnknown规则不变。

该会话含国家队仓储与进度类型，属于插件应用层；与其他插件无关的时间、正文容量、哈希及公平读取机制继续复用外层`CRS.Common`，不为目录整齐把业务合同外移。

## 测试和剩余门槛

`--application-boundaries`检查显式客户端合同、八组用例不实现客户端接口、初始化/取消/失败释放/关闭。既有并发读取、完整性巡检与短写入并行、事务去重及47项跨进程后台回归仍是行为验收入口；功能目录门禁禁止后台重新实现界面接口、功能对象获取完整仓储或后台流程回流基础设施目录。

WPF合成测试使用明确的`ResearchWorkspaceStub`及本地测试转发器；未配置的调用立即失败，生产不引用它们。仅用于旧覆盖率竞态测试的反射仓储代理已移除，改为界面端口上有控制的延迟响应；独立读取和并发事务继续由真实仓储测试验证。
