# 工作台顶栏与紧凑页头

日期：2026-10-27。用户两张现状截图显示：顶部空白、菜单在内容区另占一行，再叠大标题、说明、长状态和操作栏，压缩表格及图表高度。本轮沿用原生WPF与品牌资源。

## 调整

1. 菜单上移适合当前布局。宿主提供通用`IPluginShellHeader`，顶栏预留右侧150DIP，菜单只占所需宽度，保留系统按钮和剩余拖动区。宿主不引用具体业务插件。
2. 工作台移交同一个菜单实例，正文不保留重复菜单；独立打开仍有本页导航。切换插件、返回普通页和锁定时清空顶栏引用，再恢复原页面所有权。
3. ETF页使用20DIP小标题与单行状态。完整状态和研究口径可展开，状态也可悬停查看；日期、采集、刷新及取消合并为紧凑工具栏，窄窗口允许换行。缺失、异常和待核验状态没有改成成功或零。

`BeijingTime`迁到`CRS.Common/Time`，使用`CRS.Timing`命名空间；直接格式化和缺时区保留语义不变，读入归一化仍由`BeijingClock`负责。WPF绑定适配器`BeijingTimestampConverter`继续留在Plugin.Wpf，Common保持纯BCL。
