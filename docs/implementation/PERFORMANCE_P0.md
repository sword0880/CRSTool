# 投资绩效 P0 当前实现

2026-10-16。对应[绩效需求](../specifications/PERFORMANCE_ANALYTICS_SPEC.md)。P0 功能进入代码，合成验收与真实解析验收分开记录；真实独立金额对账未通过，不能据此宣称发布验收完成。

## 使用流程

先在证券流水页导入报表，投资绩效共用同一份冻结原件，无需重复导入。勾选账户，选择区间、报告币种和 TWR 口径，点击“更新 / 重算”。支持本月、本年、上一自然年、近 12 个月、近 3 年、成立以来及自定义；保存命名组合后可重新选择。账户默认只显示别名与真实账号末四位；自动生成的富途开户名称/完整账号标签改为“富途账户 · 尾号 xxxx”，IBKR 末四位从原件读取，不使用内部摘要冒充账号。账户旁点击“查看完整信息”才展开完整别名、开户名称和账号，可主动收起；离开页面、刷新、参数变化和锁定均清除展开内容。列表、汇总、原币组成、事件和历史范围使用同一遮蔽投影；旧历史及原始别名不改写，导出底稿仍保留冻结资料并遵循现有导出确认。

“净值曲线与指数”展示报告币净资产和起点为 100 的累计 TWR，对比 SSE（上证指数，默认）、SPX（标普 500）、HSI（恒生）或 IXIC（纳斯达克综合）。2026-10-16 起绩效统一为联网操作，移除离线模式、联网授权切换和重复更新按钮。每次“联网更新 / 重算”或“更新曲线”都获取选定期间的指数历史收盘价和对比用汇率，网络失败清空当前结果并提示重试，不使用旧行情自动继续重算。请求仅含指数、期间和币种，不上传账户、持仓与交易；上证指数使用 Yahoo Finance 的 000001.SS 人民币报价，跨报告币种时获取相应汇率。会话锁定取消未完成请求。原响应保存在加密库以便核验历史；冻结历史仍可以查看、导出。证券流水仍共用现有导入，缺失净值/资金流证据不补零。指数为价格回报，不含分红；非交易日最多沿用 7 天前报价，组合仅连接有完整估值的日期。对比用汇率与组合估值汇率隔离。

重新进入页面或刷新同一份资料会保留已计算的曲线；改变参数后点击“更新曲线”直接重算。没有有效点时显示原因卡片，只有一个点时说明无法连接折线。WPF 的 Charts/DesktopChartAdapter 统一构建图表库对象；ViewModel 只请求领域曲线并调用适配层。金额、TWR 和指数归一化在 Domain 计算。曲线有界采样、支持取消；查看历史使用当时冻结资料，不重新联网改写。

文档加密密码仅在设置窗体配置（12—1024 字符、两次确认），保存到 SQLCipher，随加密备份恢复。报表导出、绩效归档及解密统一读取该设置；修改密码不会重写旧文件，解密旧文件需在设置中切换为其原密码。明文 settings.json、日志和页面不保存密码。

“资料补录”可新建账户、修改别名、确认基础币种，填写资产/现金/应收/融资负债/应付和来源，明确确认范围完整。后台仍支持有来源的原币持仓、未复权历史价格、估值日汇率和流量前后净值；未知值不填零。手工资料始终标为估算。负现金通过正数融资负债记录，不能重复扣除。

“资金流与异常检查”支持有原因的分类修订（未确认草稿仍按未知项阻断）、内部现金/证券转仓关联及来源纳入/排除。关联要求不同账户、同类事件、转出负数/转入正数，证券身份、市场及数量一致。容差在确认时冻结报告币种；以后换币种用转账日历史汇率折算。只有两侧均在当前账户和时间范围内才消除；移出一侧账户后为外部流量，跨期一侧缺失须处理在途资产。证券、换汇与复杂事件不能仅靠改名称绕过数量/金额依据；错误来源可明确排除并以完整、有来源的资料补录，原件和旧历史不删除。

## 算法与质量

- NAV = 证券市值 + 现金 + 已确认应收 − 融资负债 − 已确认应付。负债输入正数；组成与结单 NAV 比较并列出差额。
- 区间损益 = 期末 NAV − 期初 NAV − 外部净投入。借款本金、内部换汇、股息不算外部投入。不扣未真实扣款的个人最终补税。
- 外部流量完整性、收入完整性、费用完整性分别确认。缺完整性或待匹配/未知事件时，不把缺失项目当零。
- 精确 TWR 在已确认时区、时点的外部流量前后估值切分并几何链接，输出区间累计。只有单账户且没有外部流量时，两端净值足够；跨市场精确时点缺失不冒充精确结果。
- 日末重建 TWR 明确假定流量在日末发生；有外部流量时需要每个日历日完整快照，周末也不自动沿用。允许离线填入有来源的快照，但质量明确降为重建/估算。
- XIRR 输出年化值，使用实际天数 / 365、组合边界外部流量与期初/末 NAV，遵循 [Microsoft XIRR 的定义](https://support.microsoft.com/en-us/excel/functions/xirr-function)。无有效正负号、未收敛或多解返回不可计算。非常规现金流即使有限扫描仅发现一根，也不把扫描当唯一性证明。
- 成立以来从各账户共同可用净值起点开始，不把开户之前或缺失期初填成零。不完整快照仍不可计算。
- 已实现/未实现采用独立 `IntervalMarketFIFO.v1`：期初持仓按期初市值建立区间成本，买入含费、卖出减费，拆股调整数量不改成本，内部转仓搬运原成本。它是区间市场损益，不是税务 FIFO、开户以来成本或完整汇率归因；持仓数量/成本链缺失则留空。
- 价格默认要求估值日一致，可明确配置 0—7 日回退；回退标 Estimated，期间有拆股/复杂事件则拒绝。原始持仓数量只接受未复权价格，不混用复权价格与实际拆股数量。
- 汇率只使用输入中同日直接、逆向或经 CNY 交叉的历史汇率。冲突或资料不足拒绝计算；不借用年度税务汇率或实时行情。
- 每项指标显示 Verified / Reconstructed / Estimated / InsufficientData 的中文标签；“原币资产组成”及 Excel 保留原币、折算值和来源。独立损益桥接缺证据时留空，不用公式恒等式制造零差额；独立证据差异超限时保留差额，阻断损益和 TWR/XIRR，不自动调整收益。

报告币种预设 CNY/USD/HKD，计算模型接受三位大写原币。容差配置采用报告币绝对容差、相对比例和最小货币单位的最大值；所有原币组成仍分别保存。现阶段不提供原币逐项对账阈值表，见[验收缺口](../validation/PERFORMANCE_ACCEPTANCE.md)。

## 券商映射边界

IBKR 读取实际 Activity Flex 的 AccountInformation、EXECUTION Trades、DETAIL CashTransactions、CashReportCurrency 和 OpenPositionsSummary。成交与现金事件各保留一份；现金汇总只用于完整性核对，不再生成收入/流量。账户 ID 为带券商前缀的散列，界面展示别名。缺 AccountInformation.currency 时，现有模型保留 USD 编辑初值且 BaseCurrencyConfirmed=false，不据此生成 fxRateToBase 汇率；这是既有行为，本次重构不修改。缺失币种的显式模型改造需另做缺陷修复及兼容评审。FX 来源仍须核对，同日不一致则阻断。复杂公司行动、衍生品、转仓缺依据等保留 Unsupported。

富途读取“账户信息、交易流水、持仓总览、资产进出、资金进出、资金总览”。不把年度收入主表再次转成现金事件。原件缺证券市值时只保存数量和未知金额，须补录价格；基础币种预设 HKD 只作待确认编辑初值，确认前不能用整体表单补录净值。源文件期初日期/数量仍需核对；证券转仓或复杂动作缺公允价值/身份关系会阻断，不以税务成本替代。

## 存储、导出与恢复

### 2026-10-14 绩效架构整改

`PerformanceCalculator` 的运行入口按准备输入、生成指标、生成账户行、组装结果编排。结构校验、估值/汇率选择、资金流匹配、收益率调度和质量/证据累积分为独立组件；既有 XirrSolver 与 PerformanceCostCalculator 继续复用。单次上下文深复制数组和估值组成，按账户/日期/口径、证券/市场/币种、货币对/日期及事件建立只读索引，索引不跨快照缓存。组件可以在不加载桌面、数据库和网络的条件下独立验证。

两券商由独立 IbkrPerformanceAdapter、FutuPerformanceAdapter 处理，旧 PerformanceBrokerImporter 仅保留调用分派。富途先冻结共享解析器产生的 BrokerActivityFacts（不可变交易、现金、持仓、来源、问题集合），再投影绩效；事实不含税务 FIFO 结果。2026-10-20续项将IBKR原件结构读取统一为不可变BrokerSourceDocument，税务、绩效、现金对账和账号读取共用来源模型，同步绩效传递已读快照。既有金额/分类映射与冻结输出保留；完整类型化账本、历史读取版本持久化及独立Golden仍待验收，见[来源事实边界](../architecture/BROKER_SOURCE_FACTS.md)。

工作区内容摘要覆盖账户、事件、估值、价格、汇率、覆盖证据、转账及分类修订，不再以条数判断相同资料。计算参数序号、运行身份和指数选择在异步任务完成时再次核验；过期任务可保留其真实冻结历史，但不作为新输入/新参数的当前结果显示。历史载入始终显示其冻结口径，锁定清除会话；导出绑定显示时的运行，选择保存位置期间结果失效则不提交。

运行清单从冻结输入与结果生成，包含输入摘要、算法/成本版本、数据模型、来源/行情/汇率数据集、结果指纹与阻断理由。Excel“版本依据”与加密 evidence.json 展示该清单；历史未持久化的解析规则版本显示 Unrecorded，不以当前程序版本冒充原解析版本。数据库字段、历史 JSON、SQLCipher 及 CRS.EncryptedExport.v1 容器均未迁移或重写。

回归输入/输出位于 `tests/CRS.Tests.Domain/Fixtures/performance-v1.json`，券商事实位于 `tests/fixtures/performance-imports-v1.json`，复杂度评审基线位于 `tests/fixtures/performance-complexity.json`。复杂度采用 SDK Roslyn 语法树的分支计数和含有效 token 的行数：新方法超过 15/50 或既有高复杂度方法超过已评审基线时失败，不把该计数冒充完整控制流圈复杂度。先完成 Release 构建，再运行 `tests/Verify-Architecture.ps1`；领域冻结回归使用 `dotnet run --project tests/CRS.Tests.Domain -c Release --no-build`，合成基准增加 `-- --performance-benchmark`。

Domain/Performance 只负责纯计算；Application/Performance 暴露用例；Infrastructure/Performance 负责解析、SQLCipher 和报表；WPF 仅调用用例。税务运行与绩效运行分别存储。

独立模块表 `performance_settings / performance_documents / performance_runs`（金融数据模型仍为1；设置JSON新写2、兼容读取1，解析审计记录V1） 位于现有 SQLCipher 库。原件 ≤25 MiB、单份规范数据/快照 ≤64 MiB、设置 ≤4 MiB、历史索引 ≤64 KiB（列表最多 100 条，不读取完整历史载荷）、最多 500 原件、规范资料总量 ≤128 MiB；账户 100、事件/净值 20,000、价格/FX 50,000。写入超出 2 GiB 备份容量回滚。未知/部分表结构不会自动覆盖。

每次原件按 SHA-256 去重，稳定 IBKR 业务键经济字段一致才合并，否则拒绝。载入时流式复核原件散列。分类/来源修订附原因和时间；账户与命名组合当前设置随库备份。运行冻结完整规范输入、账户范围、参数、引擎/成本版本、父运行、输入摘要与结果摘要，旧历史不随当前选择变动。重放需要版本、输入和结果一致，再创建子运行。摘要用于完整性校验，不是独立第三方签名；拥有主密码且能重写密文的攻击者不在无密钥完整性威胁模型内。

普通 Excel 导出通过统一敏感导出服务：每次确认不受数据库加密保护，生产界面拒绝 TEMP 明文输出；外部文本按字符串写入，不能变成公式。单份 Excel 总行数不超过 50,000；加密归档工作簿使用 32 MiB 有界内存流，释放时尽力清零自己的缓冲，只在内存组装 report.xlsx/evidence.json，密码需 12—1024 字符，沿用 CRS.EncryptedExport.v1，可在报表页恢复到新目录。该归档是报告，不是全量保险库备份。

全量加密备份原样包含原件、账户/组合、修订、价格/FX、估值与历史。恢复到新目录后还需认证；本机 DPAPI 槽不会随备份跨机带走。旧会话在锁定后永久失效，后台取消，页面清除数据与导出密码。
