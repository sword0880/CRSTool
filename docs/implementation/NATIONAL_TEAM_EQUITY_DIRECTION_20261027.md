# 同报告期直接持股方向

日期：2026-10-27。目标是补齐反方复核指出的“股票×机构矩阵不能回答主要行业配置”缺口，保留真实数据和完整组合的独立门槛。

## 已接通的链路

`EquityDirectionProjection`位于Core的Equity领域目录；`EquityStore.Direction`负责普通SQLite查询、原件绑定及人工核验历史；Equity类型化用例和独立Worker客户端部分传输完整报告。现有直接持股页新增“持仓方向”页签，分别展示行业/风格、核验依据、覆盖缺口。界面不计算行业权重、不下载原文、不直接访问数据库。

复用既有数据库会话、独立只读事务、取消、命令受理和公共`JsonDocumentBlocks`完整分页机制；没有增加项目或第二套调度器。当前Worker客户端九个源码部分仍按七个功能合同归档，后台仍是九组用例。

## 金融口径

- 范围固定为查询时全部启用的股票观察池，不随顶部搜索、关注或机构筛选偷偷改变分母；停用股票不参与。配置范围不是完整机构组合。
- 报告期必须相同。留空时选当前已核披露的最近报告期，其余股票缺少该期数据则列缺口，不混入各股票的最新期。查询是当前资料的截面，不承诺重建历史时点的完整可知信息或历史股票池。
- 只纳入已核具名A股账户快照；待核账户、未列示、原件异常和同报告期冲突不变成零持有。具体账户按市场、证券及账户去重；重复有效记录拒绝计算。直接持股与ETF间接暴露不相加。
- 行业核验绑定披露ID、原件摘要、标准及版本、行业代码/名称、原文页码和审核记录，仅对这一份披露的报告截止日有效。风格可留空，不通过证券名称、机构名称或未勾选战略来推断风格、目的或集团归属。
- 期末价为可选原文事实：当前只允许同一已核PDF明确披露的报告截止日A股未复权人民币收盘价，需另填价格页码。没有原文依据则不计算。尚未接入独立行情来源、报告日休市时的有证据前一交易日取价或自动分类，不能用当日价格/复权历史替代。
- 市值按该证券已核股数乘匹配期末价计算。只有同机构、同持仓性质的全部已核样本有行业及价格，并且分类标准版本统一时，才计算这一样本内的权重。战略、证券投资和未知性质分别使用分母；不同标准不拼接。机构间不共享分母，不跨证券相加股数或持股百分比。
- 已有本期披露证据损坏、冲突或部分具名账户未核时暂停权重，不能剔除后把剩余部分重新归一为100%。全局原件校验发现损坏时，独立只读查询可能整体返回不可用；页面移除旧报告，不返回空成功。

`WholePortfolioProven`始终为false。即便某个已核样本的行业权重为100%，也不证明该机构真实组合全仓这个行业，更不能证明每日交易或退出。

## 核验与运维

`equity-direction-review`是默认关闭、不开机运行的管理员手动作业，复用宿主持久命令。使用已登记PDF，不重新联网；不会自动批准待核持仓或更改原来的期间可比性。

普通SQLite新增`equity_direction_review`，保留稳定请求ID、请求参数摘要、完整核验参数、原件摘要和真实核验时间。更正必须携带读取时的上一核验版本；陈旧窗口不能覆盖新事实。同ID/同参数重放幂等，同ID改参数拒绝，失败或取消不留下成功回执。已存在表但迁移记录缺失、已记录迁移但表丢失或版本未知，启动拒绝自动重建。

界面修改报告期立即清除旧报告和原文确认；修改行业、价格或审核字段也会撤去确认。迟到旧查询不能覆盖新报告期。读取者可查询日期、选择持仓和查看原文，审核权限仍由后台管道实际身份核验。
