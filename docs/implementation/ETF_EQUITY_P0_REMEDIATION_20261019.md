## 数据状态规则

- 采集尝试状态与事实有效性分别记录。重试失败不删除此前通过审核的事实；覆盖率可以显示已有有效事实，同时显示最新请求失败。
- 空响应在已核验交易日记为 `NotPublished`，中文为“本次未返回份额”；该状态不证明官方尚未发布。无日历时记为 `Missing`，不伪造交易日或有效覆盖。
- 只有原有事实质量链允许的有效份额参与计算。异常修订依然阻断，不能凭阶段日志 `Accepted`、服务运行或任务查询完成制造事实。
- 取消持久记录 `Interrupted`。强杀遗留 `Expected`/`Fetching`/中间阶段可供查询；本轮不把强杀或断电恢复宣称为已验收。
- 采集尝试及阶段追加保留；不会清理旧失败以制造连续成功。采集阶段在后台应用用例和加密市场库处理，WPF 仅展示和交互。
- 新增表使用 `CREATE TABLE IF NOT EXISTS`，不清库，不更改税务库；桌面和后台需要配套更新。旧数据不会追溯伪造本轮新增的采集尝试。
