# 公式金额、预计金额与未知值

2026-10-13。税务页面和明文／加密 Excel 共用 `TaxSummaryPresentation`，按“项目、人民币金额、说明”逐行显示，不在界面重新计算税额。

“辅助测算补税（原始公式）”保留冻结 `Summary.SupplementTax`，明确只供核对原始公式，不能当作完整年度预计值或申报结论。“年度预计补税（状态允许时）”只使用已保存的 `CalculationResult.EstimatedTopUpCny`，不从原始公式或旧 `Summary.EstimatedTopUpCny` 回填。

预计金额展示门槛沿用完整结果、已确认数据、已匹配对账、可复核使用标签及汇率来源确认；不满足或未保存预计值时保持 null。页面顶部与表格使用同一门槛，未知值显示“不可确定”；Excel 金额留空，说明明确空白不等于零。已满足状态且保存的真实零值仍输出 `0.00`。

证券收益行标注“已确定部分”；存在未知收益笔数时披露未纳入的笔数，不能因为已确定部分为零而推定完整年度收益为零。股息／利息、辅助税额和辅助抵免也有核对范围说明。本次没有修改 FIFO、税率、税额公式、抵免法定规则或已存历史金额，仍属于辅助计算与人工复核范围。

`TaxPresentationChecks` 覆盖部分／未知金额、原始公式、旧字段不回填及真实零值。`TaxAmountViewChecks` 核验页面顶部和表格，`ExportChecks` 读取实际 Excel，验证未知金额空白与真实零值的不同输出。加密报表采用同一工作簿生成器，金额语义一致。
