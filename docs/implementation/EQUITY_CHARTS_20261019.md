# 直接持股图表与机构总览

## 范围

用户同意采用“总览矩阵 + 单股持仓点图、可比增减柱图”的展示方案。本轮扩展桌面展示，复用后台已经提供的持股、披露及历次变动查询；不增加桌面下载器、数据库写入或持仓变化计算。

## 使用

- “持仓与变动”选择股票/账户，详情的“持仓与增减图”上下展示持仓离散点和可比净增减柱，两图报告期坐标一致并同步缩放，可重置范围。
- 详情中的机构/具体组合选择器沿用顶部筛选范围，切换所选股票的具体持有人。同一简称核验为不同主体的记录不混成同一持仓序列。
- 持仓点可切换原披露的持股比例，分母为总股本；不会从股数自行推算比例。增减柱始终是后台确认的股数变化，不把比例差当买卖量。
- 点击数据点或柱可选中对应报告，显示报告截止日、公告日、比较起点、状态、性质与原文。没有图形的未列示等记录，可用报告记录选择器或历次变动表查看。日期区分报告期与公告日。
- “股票 × 机构总览”沿用顶部机构、性质、搜索及关注筛选，按股票列出五类机构及待主体核验状态。单元格统计披露记录数，详情保留具体账户、报告期和持仓性质；无记录不代表未持有。不同股票股数、不同报告时点以及战略/投资持仓不作股数汇总。

## 数据边界

- NeedsReview、Critical、Conflict不产生确认持仓点或增减柱。
- NotComparable可展示已核验持仓点，但不画增减柱；FirstListed与NotListed不画增减柱。
- 未列示保持空缺，不填零、不前向填充；持仓点不连线，不能从两个报告期推断中间每日持仓。
- 真实零变化保留为零数据，不与不可计算混为一谈。增减纵轴始终包含零基线，避免仅一个负值时缩轴误导。
- 单位切换不会把待审核候选自动选成旧已核验报告。切换股票/组合、查无结果或查询失败时清理旧图、报告及选择，异步旧响应不能覆盖新选择。
- 尚未接入个股价格、成交量、成交额，也不提供实时退出概率、趋势评分或交易建议。
