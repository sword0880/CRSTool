# ETF 表格与图表加载

2026-10-25再次复现正式后台15秒超时；新测量、协商分页及原件并发修正见[后台查询超时性能记录](ETF_QUERY_TIMEOUT_PERFORMANCE_20261025.md)。本页以下保留2026-10-21历史证据，不以合成计算成绩替代最新正式管道测量；10月25新版仍首页十行，声明能力后后续页至多256行且受原46KB限额，具体安装及桌面修正状态以新记录为准。

2026-10-21 对已安装服务作只读测量：24只概览约10627ms，目录约12ms，434点历史约12701ms，38点成交统计约9096ms，整轮约32441ms。此结果是修复前的实际服务测量，不是新版本上线后的耗时。

## 修复

- 新增可选整页读取 `dashboard`：同一仓储读事务内完整核验证据原件一次，再读取概览、份额历史和成交额。原有独立查询继续逐次完整核验，不跨刷新缓存哈希结论；发现新损坏仍拒绝返回结果。
- 合并结果沿用原有最多10行/页、响应大小、快照容量及契约校验。客户端完整收齐后统一应用表格和图表，减少重复往返和曲线重建；旧服务不支持时回退原查询。
- 日历只排序一次，历史点按日期建索引；相邻净变化直接查找，不为每个日期重复扫描全年数据和计算未使用的指纹。保留缺口、日历缺失及跨市场前一交易日不同的不可计算状态。
- 快速切换取消旧份额、证据查询，版本检查防止迟到结果覆盖新选择。客户端对查询本地排队，减少 `PluginBusy` 轮询。只读管道断连会取消后台查询；写命令仍按原有持久语义处理。
- 取消多页读取时尽力释放快照；断连时仍由既有到期机制兜底。主界面刷新等待期间切换证券，整页结果也不能覆盖新图表。

## 验证

`CRS.Tests.NationalTeamWatch --etf-loading` 检查434天24只ETF的新旧算法逐点一致、单只/汇总的合并结果与独立查询一致、刷新间新损坏原件被发现、快速切换和迟到结果隔离，并运行原有图表缺口与联动检查。一次合成计算测量由1045ms降至15ms；这仅是计算环节，不是实际服务整页耗时。

`CRS.Tests.WorkerEtf --query-cancellation` 使用隔离命名管道验证后台断连取消、多页完整读取及旧服务回退。`CRS.Tests.NationalTeamWatch --business-contracts` 验证主动释放快照不能继续读取；完整 Worker 隔离套件验证新整页查询经过真实后台与分页返回。

后台合并读取和断连取消需要同时更新配套 Worker 与插件。它们已随后续任务中心修复更新到本机开发版后台，维护与健康验收见 `TASK_ACTIVITY_AND_MANUAL_RUN.md`。本节的32.4秒是修复前样本，上线后整页加载耗时尚未重新测量；后台正常采集可能继续提交真实观测，不能把隔离测试视为真实数据覆盖验收。
