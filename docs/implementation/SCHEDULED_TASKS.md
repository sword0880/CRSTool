# 主程序计划任务（2026-10-15）

> 已由[Worker任务中心](ETF_WORKER_MIGRATION.md)替代。当前主程序不创建插件调度器；“任务中心”通过IPC管理Worker，“后台服务状态”只显示宿主健康。本文下方保留早期桌面调度实现及辅助类的历史验证，不应作为当前菜单操作说明。

当前已实现主程序Quartz.NET 4.1.0驱动、可编辑持久计划、执行记录及WPF管理入口。只执行当前已启动的官方插件注册工作，不从任务文件加载程序集、类型或回调。后台服务与WPF展示模型分开，新增关键逻辑使用中文注释。

## 使用

解锁后在左侧选择“计划任务”。选择任务后可设置每天、周一至周五或每小时运行；时间均按北京时间解释，小时0—23、分钟0—59，每小时模式只使用分钟。周一至周五是计划时间，不是交易日历证明。

- 保存计划即时生效并移除本次尚未运行的首次同步；暂停/恢复直接保留原Cron和时区，重启或重新解锁不会被插件默认计划覆盖。
- 暂停停止后续自动触发，不取消已开始的执行。取消执行可取消当前工作或尚未开始的手动请求；已提交的研究事实保留。
- 立即执行通过Quartz提交，即使计划暂停也可显式执行；同一任务正在执行或排队时拒绝重复提交。
- 点击刷新更新任务状态与记录。当前不定时重载编辑区，以免覆盖未保存输入。
- 未加载插件的计划仍可查看和编辑，不能立即执行。不能通过编辑文件引入任意代码。

ETF默认计划为每天23:15，首次解锁后60秒同步最近8个自然日。首次同步也由Quartz驱动，因此暂停计划会同时阻止它；已暂停计划在下一次解锁后仍保持暂停。编辑后的常规计划不会自动补跑错过的触发点。

## 保存与恢复

主程序任务元数据位于`%LOCALAPPDATA%/CRS/plugins/scheduled-tasks/tasks.json`，与研究事实库、原件和私人税务库分离。计划按Windows用户共享，不随某一保险库切换；不含税务账户、金额、请求参数、服务令牌或异常消息。只保存任务标识、名称、Cron、时区、启停和执行时间/结果/固定故障类别。

宿主路径契约将整个scheduled-tasks目录加入证据导出保护范围，不能用插件原件/标准化文件导出覆盖任务设置、执行记录或所有权文件。

文件具有版本和大小/数量校验，写入使用临时文件、Flush及替换，宿主通过独占文件锁阻止多个进程覆盖同一份任务配置。损坏/不支持的文件拒绝加载，保留原文件，不能重置为空计划。物理断电、磁盘满及特殊文件系统的完整实机门槛仍未关闭。

执行前先写运行中记录，写入失败则不调用业务工作。完成后记录成功、失败、已取消或部分完成；源异常不能被界面命令吞掉后误记成功。进程退出留下的运行中记录，在下次获得独占所有权时标为中断；不把旧回调或执行现场反序列化后重跑。

全宿主保留最多500条记录，保留尚未结束的长任务，优先移除较早的已完成记录。计划应用/记录写入异常会阻止后续自动执行并在管理页标识；修复目录问题后保存计划或重启重试。计划文件的持久意图与内存调度更新不是跨文件系统事务；若保存后调度应用失败，界面明确提示已保存但待重试。

## 生命周期与边界

Quartz仍使用RAMJobStore保存本次会话的任务和触发器，持久计划/记录由主程序独立元数据仓储管理；不是Quartz ADO持久任务库。当前会话注册后才重建有效任务，取消令牌覆盖主程序锁定、插件停止与用户取消。关闭软件后没有常驻进程，也不会自动唤醒电脑或启动软件。

每个任务禁止重叠。取消已被Quartz取得但尚未进入回调的手动请求时，旧触发器必须失效，不能执行或移除后来新提交的请求。触发来源使用完整触发器身份判断，不通过任务名的manual-前缀猜测。

当前未提供任意代码任务、外部脚本任务、Windows服务、计划导入/导出及完整任务依赖链。ETF完整交易日历、250日历史、连续采集和生产发行门槛见[来源POC](../DATA_SOURCE_POC.md)。

## 验证

`CRS.Tests.PluginHost/TaskScheduleChecks.cs`使用真实Quartz时钟及隔离目录，验证暂停首次同步、非法配置不改文件、独占所有权、防重复、取消、成功/失败/部分完成、异常消息不落盘、恢复设置、旧运行中记录转中断和500条保留策略。中断记录测试重建JSON现场，不宣称物理断电或实际强杀已经验收。

WPF模型验证覆盖加载、保存、暂停后手动执行、结果刷新、数值/非数字输入拒绝与锁定门槛；真实窗口冒烟打开管理页、切换执行记录并检查绑定和布局。插件原有独立进程升级恢复套件继续运行，两类恢复测试不混作同一验收。
