# 行业曲线、相对估值与机会观察

## 用户需求与反方结论

新增需求：可比较不同行业的线，观察哪些行业可能低估、是否值得进一步研究。价格位置低、跌得多、PE比其他行业低，都不能单独证明低估。行业走势、行业自身历史估值位置和基本面分别展示。

本轮先实现独立领域计算及WPF视图原型，真实行业数据源、持久化、服务查询和主导航接入仍未完成。原型截图为明确标记的合成资料，不能据此提供真实行业机会结论。

## 避免重复开发与分支边界

开始修改前核对：当前工作树`main`基准`c373418`，仅一个本地工作树；远端`origin/feature/market-cycle-research-20261024`的`ca9d2bb`已有市场周期设计、领域原型及测试。本轮不复制或重写该分支的顶部/底部评分，不擅自合并或切换分支。行业功能使用新的SectorResearch文件和独立测试项目；共享文件只在必要的NAV测试入口增加命令，后续合并应同时保留另一分支的测试调用。

## 已实现的计算与展示

- 走势线：同分类、同版本、同币种、同价格/全收益口径，全部行业使用同一交易日起点100。缺共同起点的行业不另选自己的首日；缺日不补零、不延续前值，界面断线。
- 估值线：PE(TTM)与PB各自的历史分位0～100，逐日只使用该日之前的同口径资料，平值采用中间秩；不能把当天加入历史样本抬高或压低分位。
- 历史默认5年、至少252个有效样本且有效样本达到已核对日历的80%。可显式改为1～20年，参数和实际样本/分母均进入结果。缺日历边界、方法变化、分类生效前历史不能静默混接。
- 估值覆盖率需至少80%，未知覆盖率不能默认100%。亏损、非正PE、负净资产/非正PB或不适用指标保持不可计算。
- 候选观察条件：PE/PB自身分位均不高于20%、走势资料完整、最近180天内基本面覆盖足够且盈利同比未恶化。缺基本面保留无法判断，盈利恶化提示进一步核查价值陷阱。20%/80%/180天均为待验证研究参数，不是经回测证明的买入规则。
- 数据都有原件哈希、修订、取得/首见/审核时间；知识截止后的记录不参与判断。当前输出为CurrentKnowledgeResearch/NotProven，不能把回填历史当作当年已知。
- WPF只消费后端报告，支持行业勾选、走势/PE分位/PB分位切换及状态表格，不在界面计算金融事实。不注册到主导航，直至来源和服务入口具备真实数据。

官方方法资料支持必须保留计算口径：[MSCI Fundamental Data Methodology](https://www.msci.com/indexes/documents/methodology/0_MSCI_Fundamental_Data_Methodology_20240625.pdf)区分证券与指数比率及公司行为处理；[中证行业指标数据计算说明](https://oss-ch.csindex.com.cn/indexCalculationDescription/%E6%8C%87%E6%A0%87%E8%AE%A1%E7%AE%97%E8%AF%B4%E6%98%8E.pdf)中的静态PE采用年度利润且有剔除和代表性要求。因此不得将静态行业PE直接标成TTM，也不能默认其样本包含所有亏损公司。该中证说明为2020年12月V1.1，正式接入仍须核对当前有效版本及实际文件字段，不能把旧方法或官网首页当作当前行情验收。
