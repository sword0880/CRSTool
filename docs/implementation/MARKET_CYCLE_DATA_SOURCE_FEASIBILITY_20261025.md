# 市场周期数据源可行性验证（2026-10-25）

- 状态：第一轮公开资料核验完成；尚未获得数据许可、技术规格或真实黄金样本验收。
- 适用范围：CRSTool / NationalTeam 插件的市场周期 P2 数据接入。
- 结论：**可以继续实现来源授权门禁、证据契约、离线验证和存储迁移设计；暂不批准新增生产自动抓取、历史批量回填或对外再分发。**
- 核验方法：只核验交易所/指数提供机构的公开页面、现有仓库中的来源适配器及解析逻辑；未把网页可访问等同于 API 合同、持续可用或授权。

## 2. 已核验的官方来源

### 2.1 上交所历史数据产品

- 官方页面：[Market Data Products — Historical Data](https://english.sse.com.cn/markets/dataservice/products/)
- 页面声明：历史数据覆盖上海 A/B 股和指数（包括上证指数、沪深 300 及中证指数）；日终历史数据格式为 CSV，按年订阅，最早日期为 1990-12-19。
- 页面同时区分实时 Level-1/Level-2 市场数据与历史数据产品，并给出上交所信息网络有限公司/CIIS 联系方式。
- 判断：这是目前最清晰的**官方历史指数数据候选**，但不是已确认的免费、可任意抓取数据接口。进入实现前应取得适用客户类别的规格、费用、字段说明、历史更正机制及个人本地研究/自动下载/持久化的许可范围。
- 不应因为公开页面显示 research and market analysis 就推断所有批量下载、长期保存、再分发用途都已获授权。

### 2.2 上交所每日股票统计

- 官方页面：[每日股票情况](https://www.sse.com.cn/market/stockdata/overview/day/)
- 页面当前显示每日股票情况，并提供“2021 年 12 月 24 日之前”的历史概况链接。
- 仓库已有实现：[OfficialMarketActivitySource.cs](../../src/Plugins/CRS.Plugins.NationalTeam.Jobs/Infrastructure/OfficialMarketActivitySource.cs) 使用 query.sse.com.cn/commonQuery.do，解析 TRADE_AMT、TRADE_VOL，并对日期、响应标识、产品代码和数值格式做校验。
- 判断：官方页面能证明存在日度统计展示，但不能证明该页面底层端点是受版本控制、具有 SLA 的公共 API。PRODUCT_CODE=17 与金额/成交量单位的真实含义，必须使用官方字段说明和真实黄金样本复核，不能只靠合成测试。

### 2.3 深交所市场统计

- 官方统计资料：[深圳证券交易所市场统计年鉴（2023 卷）](https://docs.static.szse.cn/www/market/periodical/year/W020240814360443176703.pdf)
- 仓库已有实现：[OfficialMarketActivitySource.cs](../../src/Plugins/CRS.Plugins.NationalTeam.Jobs/Infrastructure/OfficialMarketActivitySource.cs) 使用深交所 ShowReport 页面接口，检查 CATALOGID、TABKEY、txtQueryDate、深市合计和成交金额/成交量字段。
- 判断：年鉴/统计页面可以支持汇总口径研究，但不等同于完整、可批量回放的日度历史数据合同。现有 JSON 页面端点仍须通过真实响应样本、字段单位、历史可用区间、限流及许可范围验证。
- 深交所官方规则材料中曾明确交易信息归属交易所，并对未经许可的使用/传播作出限制。该条款的现行版本、适用范围和个人本地研究的具体许可，应由深交所确认；本报告不替代法律意见。[官方规则材料示例](https://docs.static.szse.cn/www/fund/guide/W020210331716400647184.pdf)

### 2.4 中证指数

- 官方网站：[中证指数有限公司](https://www.csindex.com.cn/)
- 官方指数事实表可用于核对指数代码、样本范围、发布日期和编制说明，例如[沪深 300 指数事实表](https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/indices/detail/files/zh_CN/000300factsheet.pdf)。
- 本轮未确认中证指数官网存在允许本项目自动批量下载、长期保存且提供点时修订版本的免费日线 API。
- 优先候选是先向上交所历史数据产品确认沪深 300/中证指数历史字段覆盖；也可直接向中证指数咨询授权。未确认之前，不实现猜测的 JSON 端点或依赖网页内部请求参数。

## 3. 市场广度的特殊难点

市场广度不是一个普通的指数行情字段。即使取得今日的全市场个股列表和价格，也不能据此重建历史广度。

必须同时具备：

1. **历史证券宇宙**：每个交易日哪些证券已上市、仍可交易或处于停牌/退市整理状态；保留退市和吸收合并证券的历史记录。
2. **历史日线与公司行为**：价格、成交状态、除权除息/拆并股调整、上市首日和停牌处理。使用今天回溯修订的后复权历史，可能改变历史时点的均线与广度；严格点时回测必须冻结公司行为版本或明确采用不会受未来更正影响的算法口径。
3. **统一统计范围**：明确 A 股范围是否包括主板、创业板、科创板、北交所；是否排除 B 股、基金、REIT、风险警示股、上市不足 20/60 日股票、停牌股。范围变化必须升级 UniverseDefinitionVersion。
4. **分母与快照证据**：每个日期记录 UniverseSnapshotId、快照哈希、定义版本、纳入/排除原因及证券数量。不得使用当前 security_master 或 ETF 观察名单作为历史全市场分母。
5. **覆盖门槛**：证券缺价、公司行为未审核或历史证券宇宙无法还原时，该日广度必须标记不完整，不能把缺失证券从分母静默移除。

结论：在获得可合法使用的证券级历史数据和历史证券宇宙前，市场广度只能使用合成测试，不能声称具备真实全市场覆盖或通过严格样本外回测。

## 4. 点时回测的硬限制

- FirstSeenAt 是系统实际首次获取时间，不是交易日期，也不能从今天的历史行情反推。
- 批量回填的历史数据即使包含 10 年价格，也通常只证明当前可取得该数据；若缺少历史采集存档、来源发布时间或供应商版本历史，就不能声称这些数据在过去的评估时点已经可见。
- 因此需要把数据分为：
  - PointInTimeVerified：保留当时可见原件/修订和首次发现时间，可用于严格点时回放；
  - HistoricalFinalOnly：当前获取的历史最终值，可用于探索性统计，但不能作为严格无未来数据泄漏的样本外证据；
  - Unverified：来源、口径或完整性未通过审核，不参与模型计算。
- 正式 P2 采集上线后，应从第一天起归档原始响应、SHA-256、请求/获取时间、解析器版本和审核轨迹，为未来构建真实点时样本积累证据。

## 5. 现有仓库的复用结论

应复用而不是重造：

- OfficialHttpGateway：来源域名白名单、请求节流、禁重定向、403/429 失败退避；不得另建不受控 HttpClient。
- SourceRequestPolicy：持久化来源请求预算和阻断状态。
- RawEvidenceStore：原件内容寻址存储与哈希核验。
- source_fetch：来源 URL、获取时间、来源发布时间（可空）、原件哈希、解析器版本、状态。
- MarketRepository 与 MarketActivityRepository：已有市场成交事实、修订审核、来源证据及交易日历存储。市场周期不应另建重复的全市场成交额表。
- ReviewedExchangeCalendar：只复用已审核年份；不允许把周末/节假日推断包装成完整官方交易日历。

新增的市场周期索引日线、广度与证券宇宙事实必须与上述来源证据关联，并且与市场成交事实保持独立粒度。

## 6. P2 准入门槛

### Gate A — 来源与使用许可
- [ ] 记录适用的来源条款/合同原件哈希、审核人、审核时间、策略版本。
- [ ] 明确是否允许自动采集、本地持久化、历史回填和再分发；四项权限分别批准，不能由网页公开推断。
- [ ] 许可或来源条款不清晰时，门禁默认拒绝自动采集和历史回填。

### Gate B — 真实黄金样本
- [ ] 每个来源保存人工确认的真实原始响应/CSV 文件及 SHA-256。
- [ ] 对字段、单位、统计范围、交易日期、修订、空数据、错误页、分页、截断、异常字符和数值边界进行验证。
- [ ] 合成测试只证明解析器边界行为；不得替代真实官方黄金样本。

### Gate C — 覆盖与点时
- [ ] 价格/指数数据覆盖目标评估所需的全部已登记交易日，不跳过缺口。
- [ ] 成交额/量至少有前 20 个有效交易日基准，且排除评估日。
- [ ] 严格历史回测需要真实点时原件/版本；只有当前最终历史值时标记 HistoricalFinalOnly。
- [ ] 广度计算需要历史证券宇宙快照和个股历史价格；无法还原的日期阻断广度信号。

### Gate D — 集成和恢复
- [ ] 复用既有来源预算和原件存证。
- [ ] 来源失败、403/429、解析合同变化、缺失日和修订冲突全部失败关闭，不切换身份、不绕过访问限制、不静默回退到非官方源。
- [ ] 新数据库结构通过从当前版本升级、取消、磁盘不足、原件损坏及恢复测试；不重建或覆盖现有市场库。
- [ ] 不启用自动通知；先只生成本地研究快照。

## 7. 本轮结论与下一步

本轮只批准通用来源授权门禁、来源契约与离线测试进入代码。官方 HTTP 适配器、历史批量回填和市场广度计算，必须等 Gate A/B 证据齐全后再接入。

建议先向上交所信息网络有限公司/CIIS 和深交所确认：个人本地研究是否可以自动下载与保存数据、历史数据产品价格/规格、API/CSV 字段说明、历史修订机制及许可边界。没有获得这些确认前，不将现有页面端点升级为生产数据契约。
