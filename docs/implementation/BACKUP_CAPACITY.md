# 分块加密备份与读取容量保护

2026-10-13。新手动备份及升级前自动备份统一生成 `CRS.Backup.v2` 分块容器；旧 `CRS.Backup.v1` 加密 JSON 仍可恢复。两者均不是明文数据库兼容通道，明文 SQLite 继续只识别头部并拒绝。

## 备份和恢复

先用 SQLCipher 在线备份 API 生成独立加密快照，验证原生数据库完整性；不复制正在写入的主库文件。快照本身始终加密，完成或失败后清理组件自己生成的快照及 WAL／SHM。

新容器有固定格式头、有界 JSON 头记录和逐块有界 JSON 密文记录。每块最多 1 MiB，复用 Security 的 HKDF 用途隔离与 AES-256-GCM 认证加密。每个块使用独立随机标识；加密清单认证保险库封套、全部块标识及顺序、总字节数和数据库 SHA256。公开封套必须与认证清单中的封套相同。换序、重复、跨备份替换、截断、长度篡改、正文篡改及额外尾部均拒绝。

写入同目录随机临时容器后，完整回读实际文件并认证每块和总摘要，再持久刷新和原子移动。已有目标不覆盖；异常只清理本组件临时文件。恢复逐块认证，只将 SQLCipher 数据库字节写到随机暂存目录，全部块、总摘要、SQLCipher 完整性及结构通过后才提交新空目录；失败不提交半个目标。恢复仍使用备份生成时的主密码或独立恢复密钥，不包含 DPAPI 本机槽。

新格式支持最大 2 GiB 数据库、3 GiB 容器；头记录最多 512 KiB、每条密文记录最多 2 MiB，长度前缀超限在分配前拒绝。处理过程不将整个数据库或容器装入托管内存；每块会产生独立编码和认证缓冲，不能把“分块”当成零分配或整套程序恒定内存的保证。2 GiB 边界由代码限制，自动大库案例超过 128 MiB，尚未以 2 GiB 完整样本测量性能及峰值内存。

旧格式保留原有最大 128 MiB 数据库／256 MiB 容器恢复门槛，仍会在内存认证和解码；不会把旧格式伪称为流式读取。旧程序不支持新分块容器，恢复前须使用支持 v2 的程序。

## 容量预警

已解锁保险库的备份界面显示逻辑页容量，包含 WAL 中的数据库增长；75%（1.5 GiB）开始提示接近上限，超出 2 GiB 明确提示。关闭或未经业务认证的会话不提供容量信息，也不显示路径。

备份前检查逻辑页容量，快照取得后再按实际长度检查。保存新计算任务时，计算记录、结转和程序归档写入同一事务后检查实际页容量；超出可备份范围回滚本次任务，保留原历史。没有自动删历史、清库、降低加密强度或明文备份行为。复核和认证记录的增长仍由实际容量预警及备份前检查发现，不能宣称所有类型写入都已被容量策略封顶。

## 历史与结转读取

- 历史正文在同一读取事务内，先查询 UTF-8 字节长度，超过 128 MiB 或为空拒绝，再取出有界字节并扫描 JSON。默认嵌套深度 32、单数组最多 20 万项、所有数组元素累计最多 100 万；重复字段拒绝。普通字符串最多 32768 UTF-8 字节，规范化快照正文最多 64 MiB，运行元数据最多 8 MiB。随后才构造业务对象并核验封存。
- 新保存任务使用有界写流并验证同样的外层配额，拒绝后没有半个任务；封存和实际归档仍在原事务中生效。该保护不替代输入规范化契约、领域语义或来源真实性校验，也不代表已经给所有持久化表设置统一配额。
- 历史分页先选运行编号再投影元数据；超大或损坏 JSON 不拖垮整页，记录保留原位置并标记异常，打开仍明确拒绝。账户列表投影最多 256 KiB，名称与父编号也限定显示长度，防止列表重新拉取整条正文。
- 结转文件使用同一个只读、禁止写入／替换的句柄检查非空及 2 MiB 上限，精确读取并检查尾部，再检查 JSON 配额、格式、摘要与批次约束。没有旧 DTO 自动转换功能。

## 验证与仍开放的事项

`ResourceProtectionChecks` 在隔离 SQLCipher 库构造超过 128 MiB 的记录，验证读取前拒绝时当前线程托管分配小于 4 MiB（这只验证拒绝路径，不是整个程序峰值内存指标）、有效历史仍可用、大库分块备份恢复、旧加密 JSON 恢复、异常容器拒绝与暂存目录清理。WPF 检查接近／超限提示，原结构升级和两种凭证恢复用例继续执行。

专项入口：`dotnet run --project tests/CRS.Tests.Infrastructure -c Release -- --resource-limits-only`。完整验收使用 `tests/Run-ReleaseAcceptance.ps1`，产物目录为 `artifacts/resource-protection-acceptance`。

真实跨电脑／Windows 用户、磁盘满／断电、特殊文件系统、实际硬件锁屏与休眠延迟、全链路峰值内存及所有历史格式迁移仍开放。后续已接入[分步备份及锁定中断](LOCK_INTERRUPTION.md)，可控长备份取消和旧任务隔离自动验证通过；不能据此承诺所有硬件立即中断，仍保留 `ReleaseApproved=false`。
