# 直接持股第一版与ETF可靠性修复

2026-10-18。按用户确认开始实现，机构范围包含汇金投资、汇金资管、证金、全国社保基金具体组合和基本养老保险基金具体组合。

## 已实现

- 同一个插件新增独立导航“国家队观察 · 直接持股”。持仓表、机构/组合与性质筛选、关键词搜索、关注股票、离散报告期持仓点和原文核验通过Worker管道连接。
- 服务端先过滤，再使用有界分页快照；大记录自动缩小页长，避免持有人长名称使整页超出响应额度。快速切换拒绝旧结果回写；空结果清空旧详情；刷新保留筛选与可恢复的选择。
- 沪市公司官网十大股东XBRL自动检查，按官方脚本明确的 `commonSoaQuery.do` / `COMMON_SSE_PL_XBRL_TOP10SHAREHOLDERS` / `stockId` 请求，校验股票、字段、日期、记录总数、单位值域与重复持有人。原始字节保存在私有证据库。
- `REPORT_DATE`只保存为来源日期。新增事实最初是待核验；正式报告截止日与公告日均保持未知，不能据此计算机构增减持。
- 官方PDF原文下载、人工原文一致性确认、具体主体确认、报告期、公告日、页码、A股/总股本口径及持仓性质登记。数据和证据写入只在Worker。当前不自动解析PDF，不接受以网页数据日期冒充报告期。
- “汇金公司”“社保基金会”及带受托机构前缀的社保/养老账号先进入“主体待核验”；保存原文账号，只能经原文核对后分类。不会按包含关键字就自动确认法律主体。不同原文账号未经进一步身份对齐不强行合并历史。
- 股数比较由后台执行：首次列示前值未知；前十大未列示当前未知；不在榜单不设零；缺少公司行为可比性或比较证据损坏时无增减持结论。比例变化不能代替股数变化。
- 战略/证券投资性质按所选持有人单独登记，不将一只股票的所有机构都当作战略持股。
- 默认13只沪市股票是可修改的采集观察范围，不是完整国家队持仓名单。包含金融股及从官方来源发现的社保、养老观察候选；停用及关注设置不会因重启覆盖。
- 功能迁移以 `feature_schema_migration('direct-equity',1)` 明确登记，在现有加密ETF库内增加独立股票表；保留现有ETF事实和服务密钥，不清库。

## ETF可靠性

1. 官方年度休市公告登记：2026年沪深两市分别核验标题、完整节假日范围与周末闭市规则；覆盖范围之外保持未知。原件受SHA256核验。已核验闭市日不发起日度ETF/成交统计请求，不清空成交比较窗口。
2. 有效交易日尚未发布需要的数据时维持缺口，不当作休市。ETF自动游标不能越过已知缺失；计划日历不会使未来日期出现在份额图表中。
3. 同值去重考虑证据有效性；历史补采同时校验前后已有观测的异常跳变，避免倒序导入绕过审核。
4. 原件恢复到最初两份哈希后解除Q15阻断，保留损坏/恢复事件；新字节不是“原件恢复”，不自动替换已接受事实。
5. 成交统计增加接受/拒绝修订、审核记录及桌面入口。接受所选值保留所有原件并否决已见的其他不同值；未来出现新值仍冲突。
6. 手动任务返回 `RetryDeferred` 时，同一个持久命令保持Pending、保留原参数；自动触发不得抢占同任务的待执行手动请求。服务重建后仍恢复原历史区间，包括禁用自动计划的手动专用任务。

## 自查中的反方意见及处理

- 不能将源网页日期当季末：保留独立SourceDate，未核验时ReportAsOf/Published为空。
- 简称会漏掉汇金和社保：加入待主体核验候选及按报告记录的身份审核，仍禁止自动模糊归因。
- 一张股东表里战略与投资性质可能不同：性质改为按持有人登记。
- 原文损坏后不能以旧结论继续判断：事实、比较与图表依赖证据有效性，恢复需原始哈希一致。
- 后续官方更正不能被历史审核永久盖掉：新不同值必须重新审核；股东候选更正保留原版本。
- 特长持有人名称可能超过管道额度：服务端分页按实际UTF8序列化大小缩页。
