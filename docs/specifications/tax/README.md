# 税务规则与计算规范

本目录维护税务规则的法律适用性和验证门槛。**它不定义当前代码公式，也不把辅助测算升级为申报结论。**

## 不可混淆的四个层次

1. **实现事实**：代码现在怎样计算，以 TaxEngine/FIFO 实现记录和源码为准。
2. **法律适用性**：该公式能否用于某一纳税人、所得类别、来源地和税务年度，以法规来源和独立签认为准。
3. **计算证据**：某次运行使用了哪些输入、版本、汇率和人工复核资料，以计算证据规范为准。
4. **发布资格**：某个范围能否对外发布或标注为可申报，以正式发布验收为准。

任何未知成本、法规适用性、汇率或抵免证据均不得补成 0 或自动解除阻断。程序输出不能反向作为独立黄金答案；不得把“计算可复现”说成“税务机关认可”。
