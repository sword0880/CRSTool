# 冻结结果与运行证据

2026-10-11。计算与复算返回冻结结果，年度汇总和抵免复核另存新任务；持久化入口也冻结结果。全部业务集合使用 `SnapshotList<T>`，增删、索引替换及清空会抛出中文业务错误。成本 LOT 在冻结时复制，数量、成本及费用不得改写；原始外部 LOT 不会影响结果。编号、父编号、审计 JSON 和封存对象也受冻结保护。人工说明仍写入独立复核表。

`RunEvidenceSeal` v1 保存 Application、Domain、Infrastructure 实际程序集 SHA256，以及持久业务载荷摘要和包含这些字段的证据摘要。载荷含输入快照、原币事实、金额、LOT、余差、来源、状态及父任务关系，不含会话交易或封存对象自身。新计算与复算立即封存；汇总和凭证复核在保存时封存。数据库读取、复算、汇总来源、Excel 和结转生成验证已有封存；Excel 增加“运行证据”页。

固定编码标识为 `CRS.EvidenceCanonical.v1`。摘要前缀为该标识及 `|`；对象属性按 Ordinal 排序，以 `o数量:` 编码；数组使用 `a数量:` 并保留顺序；字符串使用 `sUTF8字节数:` 及原始 UTF-8；数字使用 `d文本长度:` 及无指数十进制文本，删除尾零并将负零编码为 0；布尔值使用 t/f，null 使用 n。重复对象属性拒绝，数字必须可表示为 .NET decimal。字符串不做 Unicode 规范化，null 不等同零或空串。编码用于新运行封存，不改变既有规范化输入 JSON 的摘要算法。

已有封存的运行只有三个计算程序集摘要均与当前构建一致才允许复算。构建变化时可以查看、校验和导出冻结结果，但必须重新导入原件生成新任务；不加载旧的未知程序集。缺少封存的旧历史仍按已有语义门槛读取，不补造其原始执行身份，导出明确标记无封存。

这是一致性证据，不是数字签名，不能认证券商来源，也不能阻止掌握数据的人重新制作摘要或移除封存冒充旧记录。当前未归档执行程序集字节，未封存桌面 EXE、运行时和全部依赖；不能宣称跨版本任意复现、完整执行环境保全或全部目标证据契约已经完成。外层持久化 JSON 全链路配额与兼容迁移仍待完善。

`FrozenEvidenceChecks` 验证集合和成本防改写、外部引用隔离、序列化往返、业务载荷及构建字段篡改拒绝、属性顺序和数字等价编码。`CanonicalInputChecks` 明确去除新封存以独立覆盖旧记录的结构校验，不靠封存提前拒绝来代替契约测试。
