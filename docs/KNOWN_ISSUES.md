设置数据库目录不会自动复制或迁移数据库；保存后重启才启用，原文件不变。日志关闭意味着应用不再输出操作日志，但不删除已有日志。

**明文库不兼容禁令：** 不得提供明文 SQLite → SQLCipher 转换/迁移通道，不得因无法解锁而自动重建或覆盖数据库；只允许用户在新的空位置显式创建加密保险库。不得把 Windows SID/DPAPI 作为唯一恢复条件，不得把在线登录替代数据库加密，也不得把设计文档状态算作发布验收通过。安全功能进入源码后同步更新 `TEST_SPEC.md`、`RELEASE_ACCEPTANCE.md`、`SETTINGS.md` 和当前隐私声明；除 SEC-09 完整满足外，不得借本次文档更新改变当前 `ReleaseApproved=false` 的事实。

## 已完成的本轮改进

- AR-03／09／10（部分）：结果集合、LOT 和元数据冻结；三个计算程序集及持久载荷固定编码封存，读取和导出校验，构建不同拒绝复算。见 [冻结结果与运行证据](FROZEN_EVIDENCE.md)。执行二进制归档及完整目标契约仍待完成。
- AR-12（部分）：FUTU 五年度真实原件只读验证通过，独立金额签认和 IBKR 真实样本仍待补充。见 [真实样本进展](REAL_SAMPLE_PROGRESS.md)。
- AR-09（结构）：新快照与复算／明细／原件读取共用严格校验，损坏明细清除旧交易并显示原因，见 [快照读取校验](CANONICAL_VALIDATION.md)。
- AR-08：原件单次限量读取、只读内存副本和同源 SHA256 已接入，取消／同名／缺失或冲突摘要拒绝；不生成新的磁盘原件缓存。实现与边界见 [导入一致性说明](INPUT_CONSISTENCY.md)，不替代 AR-09 严格契约或 AR-10 不可变结果。
- AR-01：历史任务页支持同年度来源勾选、跨页保留和同纳税人归属确认；按冻结原币事实统一计算，拒绝重复任务／同券商重复账户、混合年度及冲突汇率。汇总另存全部来源任务及券商账户关系，页面和 Excel 披露来源；已有汇总不能再次纳入。真实全年案例仍属于 AR-12。
- AR-02：新版规范化快照单独保存原始期初 LOT、舍入余额和完整结转，复算重新校验并只合入一次；金额、批次、余差、来源、问题和状态一致后才另存。
- AR-04：FIFO 和快照共用稳定排序。同证券同时间的跨文件／相同行序交易，以及无法证明先后的期初批次进入复核并阻断可信成本，不按文件选择顺序猜测先后。
- 历史页每页 50 份，支持全部历史翻页；概览的最近任务不随翻页改变。复算任务保留父任务编号，失败或取消不新增历史。
- 当前复算口径为 `FIFO_TOTAL_COST_V3`，完整快照为 `CRS.CanonicalInput.v2`。旧快照仍可查看和导出，不能使用新口径冒充等价复算；需重新导入原件生成新版快照。旧结转 DTO 转换仍属于 AR-05。
