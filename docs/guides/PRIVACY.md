# 本地数据与隐私验收

2026-10-13：报表／结转／解密入口增加统一后台明文授权和临时目录策略，XLSX 文本类型回归及固定日志类别已接入；窗口验收诊断不再写完整异常。明文同目录暂存仍可能有介质残留，删除不等于物理擦除；操作系统 dump 和实际分发包审查尚未关闭，见 [敏感导出保护](../implementation/SENSITIVE_EXPORT.md)。

业务结构 v2 将新任务的三个计算程序集文件存入加密库，按 SHA256 去重；这些编译文件可能包含构建标识或调试路径信息，不复制用户原件。加密 v1 升级前在保险库目录保留可恢复的 `.crsbak`，内容含原数据库和认证恢复资料，应按其他保险库备份保管；失败回滚不会自动删除已经完成的备份。应用不在库外生成 DLL 副本或动态执行归档文件，见 [升级与程序归档](../implementation/DATABASE_UPGRADE.md)。

手机验证默认开启，可在设置中经身份确认关闭。关闭后在当前 Windows 用户环境依靠受保护本机密钥进入，仍使用 SQLCipher 加密；同用户环境有访问能力者可能直接进入应用。开关保存在加密库并随备份恢复，不记录主密码或六位代码。

应用默认在 `%LOCALAPPDATA%/CRS/data/crs.db` 保存结果和复核记录；设置可修改下一次启动使用的数据库目录，桌面日志目录保存后立即生效，保存设置不自动迁移或删除已有数据。数据库使用 SQLCipher 加密，首次设置主密码；本机 DEK 由 Windows 当前用户保护的 `vault.device` 保管，日常验证 Microsoft Authenticator 六位代码进入，不保存主密码。换电脑或本机凭证失效时使用主密码／独立恢复密钥重新启用；Excel、结转和券商原件仍为明文。说明见 [保险库指南](VAULT_GUIDE.md) 与 [认证实现](AUTH_IMPLEMENTATION.md)。

默认结果包含账户标识、证券、匹配买卖金额与日期、期末成本、来源文件名／部分路径、摘要、所得及复核文本。未选择完整快照时，不保存会话原始交易集合，但仍保存这些业务结果；“未保存原始交易”不能解释为“无个人数据”。选择完整快照会额外保存规范化交易、现金、持仓、结转等事实，足以恢复敏感交易历史。规范化不等于匿名化。

新结果的运行封存保存三个计算程序集指纹和持久载荷摘要，不新增原件副本。Excel“运行证据”页披露这些摘要；摘要不是匿名化或来源认证。`sample` 已由用户声明为真实私有数据，FUTU 技术验收报告仅记录匿名原件索引、摘要、数量和状态；独立金额验收报告含真实核对金额，仍须按私有资料保管。IBKR 真实 XML 已加入只读技术验证，报告同样仅含摘要、期间、笔数和状态，不输出身份及真实金额。

导入原件一次限量读取到只读内存副本，解析及来源摘要共用该副本，不生成新的磁盘原件缓存。关闭文件后，原件的后续变更不会改变本次已解析数据和摘要；文件名、摘要及规范化事实仍按既有快照策略保存。内存中的明文及系统分页不构成安全擦除保证，详见 [导入一致性](../implementation/INPUT_CONSISTENCY.md)。

规范化快照及历史外层读取有 UTF-8 大小、深度、集合和字符串上限，并验证摘要、字段及冻结归属。结转的大小与正文由同一个只读句柄检查。损坏或超限时不自动修补或保存成新任务；不因校验而增加原件、交易或凭证的默认持久化范围。限制不等于进程总内存或所有数据库字段的全链路配额，详见 [快照读取校验](../implementation/CANONICAL_VALIDATION.md) 与 [容量保护](../implementation/BACKUP_CAPACITY.md)。新备份逐块认证，暂存恢复内容仍为 SQLCipher 加密数据库；格式、保险库标识、大小等外层元数据仍可见。

新增抵免复核保存所得国家分配、税款及凭证机关／编号、文件名和 SHA256，不复制凭证正文或本地绝对路径。用户填写的凭证名称、编号和人工复核文本可能含敏感信息；导出的 Excel 也会包含这些信息。用户应在分享前检查底稿和真实样本验收清单。

Excel 与 LOT 结转导出需要主动确认明文风险，在用户选定目标的同目录生成随机命名临时文件。只有完整写入、取消检查及当前保险库会话检查通过后才替换目标；正常失败或取消清理本次临时文件并保留原目标。临时文件也包含明文，程序崩溃／断电可能留下副本，文件删除不等于安全擦除；本机制不代替加密导出。

报表页另支持独立密码 `.crsexport` 加密容器：Excel、可用结转和运行证据在内存中生成后加密，暂存文件仅含密文。外层不写账户／年度／内部文件名，但文件大小和文件系统元数据仍可见。独立密码不持久化，操作结束、离开页面及锁定时清空；托管内存不保证彻底擦除。解密恢复明确确认明文后写入新目录，认证或格式错误不会开始恢复，正常取消清理暂存；崩溃／断电仍可能留下恢复明文。完整边界见 [加密底稿与恢复](ENCRYPTED_EXPORT.md)。

Flex 服务令牌只在当前会话和发往固定 IBKR HTTPS 域名的请求中使用，关闭应用时清空；配置拒绝包含令牌字段。下载会向 IBKR 提交令牌、查询 ID、起止日期；应用不会自动上传本地结果或凭证。日志记录固定操作信息、数量、年度及异常类别，不记录外部异常正文；日志可关闭，已有日志不随关闭自动删除。

删除数据需在退出应用后处理选定数据库及其 SQLite 辅助文件、日志、原件、导出和自行备份；当前没有“一键清除全部数据”或安全擦除功能。文件系统删除不保证不可恢复。更换数据目录也不会清除旧目录。

自动化验证覆盖默认交易集合不持久化、凭证正文／绝对路径不进入结果、取消不新增任务、日志开关和轮转、令牌配置拒绝及固定端点下载。上述检查不能替代实际安装包的网络流量检查、用户授权文案、备份／删除演练或组织隐私审核，发布验收仍保留待审核状态。

## 安全改造计划与当前声明边界（2026-10-10）

**V1 核心安全能力已进入源码，实际验证结果与公开发布门槛必须区分。** 计划新增的 [SECURITY_DESIGN.md](../specifications/SECURITY_DESIGN.md) 要求 V1.0 引入本地主密码、SQLCipher、独立恢复密钥、加密备份及旧明文库检测拒绝策略（不提供迁移）；V1.5 公开桌面版提供可选加密导出、多保险库隔离与发布审查。主密码、SQLCipher、独立恢复凭证、备份恢复及明文旧库拒绝已实现；公开版加密导出、多保险库与独立安全发布审核仍待完成。

公司管理的 Windows 电脑可能受管理员、终端安全软件、远程管理、截图与企业同步/备份策略约束。**即使数据库已静态加密，程序解锁运行时的明文、用户输入、屏幕和外部导出仍不能保证不被高权限管理组件接触。** 真实个人交易和税务数据优先在个人设备处理，公司设备上优先使用脱敏样本并遵守组织政策。

新安全版本**不会迁移或打开旧明文数据库**。原有 `crs.db`、WAL/SHM、历史数据库备份、日志、券商原件、用户下载的 Flex XML、Excel/结转导出仍可能以明文存在。检测到旧库时，程序拒绝访问并引导用户在新的空目录创建加密保险库；不会自动清理、删除或覆盖旧文件。SSD 和企业备份中的副本也不能保证被安全擦除。旧库历史记录不会自动恢复，用户需从原始券商报表重新建立数据；相关限制应在界面说明。

未来公开发布时，应再次验证实际传输端点、依赖许可、导出密码保护方式、备份恢复、日志脱敏、旧明文库拒绝策略和文件删除/留存提示，并更新用户告知文案。不得将当前不上传计算结果等同于“设备管理者绝对无法访问数据”。


投资绩效会将导入原件、账户别名、规范事件、离线估值/汇率、修订和冻结结果保存在同一 SQLCipher 库内，并进入全量加密备份。原件可能含真实账户身份；普通绩效 Excel 导出仍是明文，必须再次确认。加密绩效归档包含报告和证据，恢复后文件不再受库加密保护。见[绩效说明](../implementation/PERFORMANCE_P0.md)。
