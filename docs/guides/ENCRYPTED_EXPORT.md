# 加密底稿与恢复

2026-10-11。报表页新增“加密底稿与恢复”。输入至少 12、最多 1024 个字符的独立导出密码及确认密码，保存 `.crsexport` 文件；默认文件名不含年度和账户。容器包括 Excel 底稿、运行证据和可用的年末 LOT 结转，成本未核实不附带结转。普通明文导出继续保留并要求确认。

导出密码不保存到配置、数据库或日志，不从主密码或数据库 DEK 派生。密码遗失后无法用保险库恢复密钥恢复此文件，用户应独立妥善保管。密码框和模型在操作完成／取消、离开页面及工作区锁定时清空；托管字符串和第三方工作簿对象不能保证安全擦除。自有正文及明文缓冲在释放时尽力清零。

恢复时输入文件原导出密码，选择加密文件并确认恢复明文，再选择父文件夹。程序先认证解密并校验全部内部文件名，再写随机暂存目录，成功后提交到全新的 `CRS-Restored-<随机标识>` 文件夹。不覆盖已有文件、不自动导入保险库，也不执行或自动打开恢复资料。恢复的 Excel、证据和结转为明文，应保存在可信位置。

## 实现契约

外层 JSON 格式为 `CRS.EncryptedExport.v1`，只含版本化口令载荷、随机 16 字节盐、固定 Argon2id 参数、随机容器标识、12 字节 nonce、密文和 16 字节认证标签。不明文记录正文文件名、账户、年度或业务摘要；文件大小和文件系统元数据仍可见。

Argon2id 参数固定为 65536 KiB／3 次／并行度 2，派生 32 字节密钥；未知参数在派生前拒绝。HKDF-SHA256 用途为 `CRS.Export.Key.v1`，AES-256-GCM 附加认证数据为 `CRS.Export.v1|<容器GUID>`。与备份用途隔离，原备份 v1 编码不改变。内部正文为版本 1 的 JSON 文件集合，只允许 `report.xlsx`、`evidence.json` 和可选 `carry.json`，未知字段／重复文件名／目录路径拒绝；不使用任意 ZIP 解包。

Excel 直接写内存后加密，不先落地明文。工作簿上限 32 MiB，证据／结转各 2 MiB，正文 JSON 上限 64 MiB，读取外层容器上限 96 MiB、JSON 深度 16。以上不是进程总内存承诺，工作簿对象、JSON 解码和第三方分配另占内存。取消与锁定关联原会话，Argon2id 单次派生和 GCM 操作在返回后检查取消；最终提交前再次验证会话和取消。

密文导出沿用同目录随机暂存、持久刷新及原子替换，正常失败清理暂存密文并保留既有目标。恢复全部写完后才移动目录，正常失败只清理本次允许的文件，不递归删除用户目录。恢复崩溃／断电可能留下明文暂存；文件删除不等于安全擦除，网络及特殊文件系统的原子性与断电／磁盘满仍需实机验收。

## 自动验收

`PasswordExportChecks` 覆盖独立密码往返、短／错误密码、未知版本及参数、备份用途隔离和认证标签篡改。`EncryptedExportChecks` 覆盖密文元数据隐私、Excel／结转恢复、错误密码及认证篡改不落地、正确认证的恶意路径／重复名称拒绝、预取消、恢复提交取消清理及真实保险库锁定后原文件不变。`EncryptedReportsInteractionChecks` 检查无结果恢复、密码确认、忙碌与取消门槛、明文恢复确认及密码清理。

统一产物为 `artifacts/encrypted-export-acceptance`；真实 FUTU 样本技术复验与人工金额签认继续分别记录。加密导出不等于完整数据库备份，不替代保险库加密备份及恢复。完整发布门槛仍未关闭，`ReleaseApproved=false`。

局部修正可运行 `dotnet run --project tests/CRS.Tests.Infrastructure -c Release -- --encrypted-export-only` 单独复验容器。目录尾部分隔符规范化及取消后的暂存清理也纳入该专项。
