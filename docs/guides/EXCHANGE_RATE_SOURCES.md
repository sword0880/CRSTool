# 年度测算汇率来源

桌面端的「汇率管理」在打开时读取所选年度的汇率。开始年度核算时也会自动读取。「更新官方汇率」可重新查询。美元、港元取自国家外汇管理局公开的中国外汇交易中心人民币汇率中间价，按每单位外币兑人民币换算。人民币折算系数固定为 1。[国家外汇管理局人民币汇率中间价](https://www.safe.gov.cn/safe/rmbhlzjj/)

- 已结束年度使用 12 月 31 日的中间价。当天没有报价时，取该年最后一个有报价日的中间价，并标记为临时测算。界面与汇率底稿显示实际日期。[境外所得有关个人所得税政策公告](https://www.chinatax.gov.cn/chinatax/n810219/n810744/n3752930/n3752974/c5143076/content.html)
- 当年采用年初至今各报价日中间价的算术平均，四舍五入保留六位小数，并标记为临时测算。非报价日跳过。
- 官方服务暂时不可用时，使用同年度、同统计口径的已校验缓存。无可用缓存时，提示检查网络并重试。

已保存的历史测算保留当时实际使用的汇率。桌面正式运行时自动取价，本地的旧汇率文件仍供隔离验收和兼容调用使用。
