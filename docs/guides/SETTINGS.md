# 日志与数据库设置

点击左侧菜单栏“设置”；安全操作使用“保险库与备份”。右上角关闭按钮用于退出窗口；正在执行后台操作时需先取消或等待完成。

## 数据库

日常手机登录不显示数据库位置；首次创建或安全窗口主动选择其他位置时才展示。设置中的目录配置保留，用于用户明确调整下一次启动位置。

填写或浏览选择数据库目录，应用使用该目录中的 crs.db。首次创建设置主密码保护资料并用 Microsoft Authenticator“其他账户”扫码；已有本机凭证时只验证手机六位代码。换电脑／本机凭证失效时使用原主密码或独立恢复密钥，不重新创建数据库；恢复方式见 [认证操作说明](AUTH_IMPLEMENTATION.md)。新目录只进入创建／恢复向导，不会自动创建空数据库。旧明文库直接拒绝，不支持迁移。保存设置不会迁移、复制或删除原数据库，也不会切换正在使用的连接。

无设置文件时，默认数据库为 %LOCALAPPDATA%/CRS/data/crs.db，不自动识别或回退旧版本目录。

## 手机验证

“设置 → 登录验证”可设置“启用手机验证”，默认开启。修改时填写主密码和新的六位手机代码，点击“保存手机验证设置”；与目录／日志保存分开。关闭后下次在当前 Windows 用户环境中依靠本机受保护密钥直接进入，不显示验证窗口，数据库仍加密；重新启用后恢复手机验证码进入。开关保存于加密库，不由普通设置文件控制，备份恢复会保留备份时策略。

关闭不删除手机绑定；重新启用仍使用原手机。换电脑或本机凭证失效仍需主密码／独立恢复路径，未完成初始化或恢复不能绕过安全确认。

## 日志选项

可设置日志开关、目录、最低级别（Debug、Info、Warn、Error）、保留归档数（1—365）和单文件轮转上限（1—100 MB）。活动日志为 crs.log，达到上限后轮转归档。关闭日志不删除已有文件。默认目录 %LOCALAPPDATA%/CRS/logs，级别 Info，保留 14 个归档，单文件上限 1 MB。

此处仅控制桌面 `crs.log`，不控制独立Worker的服务诊断及任务阶段记录。Info及以下保存时会写入“桌面日志设置已应用”，Warn/Error或关闭时不会强制越过最低级别产生确认记录。没有符合级别的新事件时，文件不会增加内容。

程序仍只记录脱敏的操作和错误类型，不输出服务令牌。日志级别选择不改变现有记录内容或开启原始报告抓取。

## 保存与生效

保险库的加密备份区域在已认证时显示逻辑容量，达到 1.5 GiB 提示接近 2 GiB 上限；包含 WAL 中的增长，不展示数据库位置。新备份采用分块格式，旧加密备份仍可恢复，详见 [备份容量保护](../implementation/BACKUP_CAPACITY.md)。这些容量不是可随意调大的设置，不自动删除历史。

目录切换仍不自动迁移资料。打开已验证的加密业务 v1 库时，会先在该库目录保留升级前 `.crsbak` 再事务升级到 v2；备份失败、未知结构或高版本会拒绝进入，不重建数据库。恢复升级前备份仍须选择新空目录，见 [升级保护](../implementation/DATABASE_UPGRADE.md)。

加密底稿的独立导出密码不是设置项，不写入此设置文件；操作结束、离开报表页面及锁定时清空。该密码与保险库主密码／恢复密钥各自独立，见 [加密底稿与恢复](ENCRYPTED_EXPORT.md)。

目录必须为完整路径且可写。保存失败不会覆盖上一次有效设置。设置文件为 %LOCALAPPDATA%/CRS/settings.json，以临时文件完成后原子替换。

桌面日志的开关、目录、最低级别及轮转参数保存后立即生效，已有记录器同步更新；数据库目录下次启动生效。关闭设置窗口而不保存不会改变磁盘设置；重新打开会恢复已保存的选项。
