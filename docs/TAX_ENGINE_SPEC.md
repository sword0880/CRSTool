# 税额引擎当前实现与边界

更新日期：2026-10-10。本文描述代码中的辅助算法，不进行新的法规核验，也不把软件公式声明为所有账户适用的申报结论。未完成的证据与适用边界见 [问题清单](KNOWN_ISSUES.md)。

## 规则与金额

[TaxEngine](../src/CRS.Domain/TaxRules/TaxEngine.cs) 的 PolicyVersion 为 V1-2026-09，继续沿用项目辅助口径：

- 股息、利息按原币事实及年度汇率转换为人民币。
- 股息利息税额按其合计的 20% 计算。
- 净境外税款抵免值在零与该收入税额之间限额；年度净退税另外提示复核。
- 目标年度 Match.GainCny 合计为资本收益；其正值按 20% 计算资本收益税。
- 公式补税为股息利息限额抵免后非负余额与资本收益税之和。

金额使用 decimal，舍入由 Domain 统一处理，前台只格式化。资本亏损不在当前算法中抵减股息利息，尚无跨年度亏损抵扣算法。该描述是现有实现事实，不是新增法律判断。

## 结果可信性

Summary.SupplementTax 是辅助公式值；CalculationResult.EstimatedTopUpCny 受完整性、对账、资料问题和临时状态等门槛控制。不满足条件时保持 null，不能把部分公式值显示为完整年度确定补税。

抵免尚按年度与币种汇总，国家／地区、所得项目及证据资格尚未闭环。人工依据不会自动“改绿”或改写税额。AR-06 的业务证据门槛仍待落实。

## 多账户与历史

AnnualTaxAggregationService 汇总原币事实后调用税额引擎，拒绝缺事实、重复范围及不兼容汇率等输入；尚未接入 WPF 跨运行聚合选择。

历史结果查看与导出沿用冻结金额；后台重放禁止回退当前汇率，保留历史临时状态，但尚未构成严格复算证明。当前年度或临时汇率的结果不能自动升级为全年核准结果。

## 验证

税额基线、净退税、盈利亏损相抵、舍入、年度范围及不完整状态由当前控制台检查覆盖。真实全年成本、抵免证据与适用口径需独立验收，见 [当前问题](KNOWN_ISSUES.md)。
