## 反方审查与代码结果

仅有认证封装不足以防止未经确认的导出、授权重放或审计失效后泄露。新增
`RecoveryExportSession`：每个预先冻结/核验的快照建立独立短期会话，调用者必须来自服务端
Windows 令牌验证后的 BackgroundCaller。类内的 CanManage 字段不是认证来源，也不是
OS 权限边界；生产接线尚未实现，普通请求不能创建本会话。

会话固定为导出主密钥操作，绑定管理员 SID、准备/确认请求 ID、包 ID、清单 SHA256、随机
确认挑战和两分钟单调时钟期限。确认必须再次具有管理权、同一 SID、不同且非空的确认请求 ID、
匹配上下文/挑战及显式确认。恢复凭据仍要求独立 32 字节高熵秘密；挑战不是恢复凭据。
清单包含快照 ID 的规范和全部内容，必须由后续协调器核验；本组件只绑定摘要，不证明停机一致性。

在读钥回调前必须完成 Authorized 审计；在返回密文前必须完成 Sealed 审计。任何确认尝试
先消费会话，之后的失败、超时、取消、审计失败、源钥失败和并发重放均不得再次读钥。
单调期限在授权审计后、读取后、最终审计后再核对，审计阻塞不能延长授权。单调时钟倒退也拒绝。
会话销毁或进程退出即失效；新会话产生新挑战。

期限是读钥准入与返回门禁，不能中断任意同步回调；生产协调器仍需有界 I/O/排空及失控停止策略，
不能据本对象承诺两分钟内释放租约或完成导出。

审计采用固定结构，只包含 SID、请求 ID、包 ID 和 Prepared/Authorized/Sealed 阶段，
不接收秘密、挑战、清单内容或任意异常消息。源钥和审计异常归一化为固定错误类别，无 InnerException。
Sealed 只说明封装已完成，**不代表备份已交付或完成**；其后取消/过期仍可无返回，必须保留结果未知。
回调返回必须表示实际持久审计成功，排队/内存列表不能替代持久回执；本测试中的列表仅用于故障注入。

读取回调必须返回会话独占的密钥副本，不能返回运行中 Worker 共用数组；会话负责清零。
不返回明文；失败时清零本次密钥、未返回密文及挑战。输入凭据由调用者清零，不持久保存。
新增 `ServiceKey.OpenExisting` 供后续维护流程使用，仅以 FileMode.Open 有界读取，
空目录缺钥也不初始化；保留实际运行账户 SID、原 DPAPI scope/entropy 和链接检查。
既有 `Open` 首次初始化语义不变，其已有密钥分支复用该读取实现。

## 接入生产前必须补齐（阶段 2b，未实现）

- 专用受限管理管道中的实际令牌、操作确认及受保护凭据交付，不接受请求自报 SID/权限。
- 以仓储持久维护请求索引、跨会话/跨重启重放语义、全局与按 SID 容量限制、拒绝/取消审计；
  不能仅靠本对象的进程内一次性状态宣称持久幂等。
- 正式授权/审计存储错误须进入 Worker StorageFault、停止新任务；本组件本身不控制调度器。
- 停收工作、排空、维护/数据独占租约的交接与全树 ACL 验证；会话在租约持续持有期间有效。
  获得租约后只能通过 OpenExisting 读取，不能使用可能初始化的 Open；任何检查失败关闭。
- 一致性全量快照及规范清单、业务文件认证加密/有界打包、安全输出及独立恢复凭据确认保管。
  不向 argv、环境变量、日志、明文临时文件、普通用户或通用 LocalService 开放秘密。

目标机重封装、全部 SQLCipher/Schema/原件只读核验、显式激活与双干净机器演练仍属后续阶段。
本轮没有新的恢复 IPC/CLI/配置开关，不操作真实用户密钥、生产数据或 SCM，不自动合并。
