此前的“23万”是文件和目录项总数，并非23万个文件夹。升级前只读枚举有383个子目录（含logs、maintenance、plugins本身），大量目录项是历史快照中的重复文件。

| logs | 13 | 0 | 3.75MiB |

升级前有41份带清单的升级快照，本次升级后为42份。每次升级会对当前业务数据保存一致性副本，既有流程不自动淘汰旧代次，因此长期累积。当前插件数据库、原始证据、密钥、维护记录和恢复必需副本不能按“缓存”删除。

后台自带只读审计以开始时的已提交维护代次为准，识别出37份较早升级副本为清理候选：200578个文件、约8318.74MiB（8.12GiB）。当时保留当前引用快照、最近两份已验证历史副本，另保留一份身份/路径/文件清单无法完整核实的副本`73215e55abac4261875ec22a9f6bb86b`。未发现超出保留期的可清理日志。

候选识别并不等于已经删除，或已经对所有候选字节完成删除前验证。实际清理须在本次升级已提交后重新生成当前预览，继续保留当前引用快照、至少两份完整历史副本以及无法核实的资料，再由后台按固定范围逐文件核验后执行。本次未执行删除。
