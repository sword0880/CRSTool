## 本轮验证

- Release 解决方案构建零警告、零错误；新增界面和基础设施测试后分别重新构建通过。
- Domain、Application、Security、Infrastructure、Wpf、Verification 六组回归通过，综合入口原有 68 个场景通过。
- `AccountPeriodChecks` 验证新期间契约与完整快照重放；`AccountPeriodFileChecks` 验证严格清单、凭证内容摘要、原件不变、加密往返和 Excel 字段；`ImportInteractionChecks` 验证选择、取消、清除、请求传递与券商隔离。
- `LockInterruptionChecks` 使用原生在线备份步后的单次暂停验证取消及 5 秒测试期限，不能等同任意硬件延迟承诺。
- 架构检查与补丁空白检查通过；WPF 隔离窗口冒烟通过，导入截图在 `artifacts/p0-followup-acceptance/wpf-import.png`。

## 后续人工材料

独立计算记录应由人工或独立工具形成，注明年度、账户范围、期初真实成本、收入与收益、折算依据、税额及抵免凭证关系，逐项与程序输出比较。没有材料时继续显示验收未通过。

设备恢复演练应使用可丢弃的测试保险库，分别测试新 Windows 用户及另一电脑，以备份时主密码或恢复密钥恢复到新空目录，核对历史、成本和再次备份，检查原件与旧库摘要不变。硬件锁屏／休眠和磁盘故障必须另行记录真实观察，不能用当前自动测试结果代替。
