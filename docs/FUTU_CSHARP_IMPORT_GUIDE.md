# 富途文件导入

## 两类文件分别选择

1. 在“数据导入”选择 FUTU 和测算年度。
2. “股息收入”选择年度收入 XLSX 或支持布局的文本 PDF；它是股息／利息的主数据。
3. “交易明细”选择年度交易 XLSX，也可选择连续且不重叠的历史年度交易工作簿。
4. 选错后点击对应的“选择 / 替换”重新选择，只替换这一类文件；“清除”只移除对应文件。取消文件对话框保留原选择。
5. 有期初持仓时选择 C# LOT 结转 JSON 或提供完整历史成本；真实无持仓才确认。市价不替代 LOT 成本。
6. 确认报告未过滤范围，再点击“导入并开始计算”。更换或清除任何输入都会使旧结果、图表和导出资格失效。

两个选择项不能指向同一个文件。后台仍会检查实际文件结构；把文件放进选择框不代表格式已通过。只有收入文件可以辅助测算，但交易及税款资料缺失会持续提示。运行中不能改文件。

## 文件及核对范围

交易 XLSX 读取账户、流水、持仓、资产与资金事件。年度收入 XLSX／文本 PDF 是收入主表，资金派息仅核对，不重复计税。表头顺序可变，公式／错误单元格及无效年度拒绝。

缺总费用、身份无法绑定、原始金额差异、重叠主报告与未支持证券事件保留复核或拒绝。账户、券商、市场、证券和币种分别隔离。PDF 不支持扫描件和未知布局，具体字段见 [字段映射](FUTU_FIELD_MAPPING.md)。

数量和现金一致不等于全部对账：富途资料不提供独立逐笔券商 FIFO 盈亏，不因此发布确定的全年预计补税。未知事件不会因人工备注自动解除。

## 输出与验收

Excel 包含年度收入、成交金额核对、资金及证券事件、FIFO、辅助汇总和复核底稿。结转仅在年末成本及数量满足门槛时开放。

使用 [验证入口](../tests/README.md)执行合成布局、费用与原始金额、碎股、现金、账户和事件边界检查。真实全年、严格重放、旧结转和抵免证据仍见 [当前问题](KNOWN_ISSUES.md)。
