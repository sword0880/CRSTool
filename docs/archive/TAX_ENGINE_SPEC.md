# 中国个税计算规则说明（Tax Engine Spec）V1.0

## 1. 文档目的

本文档用于规范富途海外证券个税助手 V1 的税务计算逻辑。

目标：

* 固化税务引擎计算规则；
* 保证同一输入得到唯一税务结果；
* 为开发、测试、用户核对提供依据；
* 作为“辅助测算工具”的税务说明文档。

重要声明：

本工具仅用于税务辅助测算，不构成税务申报建议或专业税务意见。

用户最终申报责任由本人承担。

---

# 2. 适用对象

本规则适用于：

中国税务居民个人。

定义：

在中国境内有住所，或者无住所而一个纳税年度内在中国境内居住满183天的个人。

其来源于中国境内和境外的所得，应依法缴纳个人所得税。依据《中华人民共和国个人所得税法》。

---

# 3. V1 涉及所得类型

V1 仅处理以下三类境外所得：

## 3.1 利息所得

来源：

* 券商现金利息；
* 存款利息；
* 其他 Interest 类型收入。

对应税目：

利息、股息、红利所得。

税率：

20%。

---

## 3.2 股息红利所得

来源：

* 美股股息；
* 港股股息；
* ADR 股息。

对应税目：

利息、股息、红利所得。

税率：

20%。

---

## 3.3 财产转让所得

来源：

股票卖出形成的资本利得。

对应税目：

财产转让所得。

税率：

20%。

依据《个人所得税法》，财产转让所得适用比例税率20%，以收入减除财产原值和合理费用后的余额为应纳税所得额。

---

# 4. V1 不支持的所得

以下所得不纳入计算：

* 工资薪金所得；
* 劳务报酬所得；
* 稿酬所得；
* 特许权使用费；
* 经营所得；
* 财产租赁所得；
* 偶然所得；
* 数字货币收益；
* 基金特殊分配；
* 期权收益；
* 期货收益。

发现相关数据：

提示用户人工处理。

---

# 5. 汇率规则

V1 使用系统内置年度平均汇率。

配置：

exchange_rate.json

示例：

{
"2021": {
"USD": 6.4515,
"HKD": 0.8291
}
}

换算公式：

人民币金额

=

原币金额 × 年度平均汇率

保留：

人民币两位小数。

四舍五入。

---

# 6. 股息及利息税计算

## 6.1 应纳税所得额

股息应纳税所得额

=

股息收入人民币合计

利息应纳税所得额

=

利息收入人民币合计

合并计算：

股息利息所得额

=

股息所得

+

利息所得

---

## 6.2 中国应纳税额

税率：

20%。

公式：

股息利息中国税额

=

（股息所得

+

利息所得）

×

20%

---

# 7. 境外税额抵免

## 7.1 基本原则

允许抵免：

境外已实际缴纳的个人所得税性质税款。

例如：

美国股息预扣税。

不允许抵免：

* 交易佣金；
* 印花税；
* 平台费用；
* 非所得税性质收费。

---

## 7.2 可抵免金额

公式：

可抵免税额

=

Min（境外已缴税额，

中国对应税额）

即：

不得超过中国应纳税额。

依据《个人所得税法》，境外已缴个人所得税税额准予抵免，但抵免额不得超过依照中国税法计算的应纳税额。

---

## 7.3 补税金额

公式：

股息利息补税

=

股息利息中国税额

−

可抵免税额

最低值：

0。

不得为负数。

---

# 8. 财产转让所得计算

资本利得计算：

详见《资本利得计算规则说明（FIFO 实现规范）》。

年度资本利得

=

全部 Match 收益人民币合计。

允许负数。

---

# 9. 财产转让所得税计算

若：

年度资本利得 > 0

则：

财产转让所得税

=

年度资本利得

×

20%

若：

年度资本利得 ≤ 0

则：

财产转让所得税

=

0

说明：

V1 采用保守原则。

亏损年度不产生应纳税额。

---

# 10. 亏损处理规则

V1 规则：

年度亏损不得抵减股息利息所得。

即：

股息税与资本利得税独立计算。

例如：

股息：

10,000 元

资本亏损：

−50,000 元

结果：

股息仍需缴税。

资本利得税：

0。

---

# 11. 跨年度亏损规则

V1 不支持亏损结转。

即：

上一年度亏损，

不得自动抵减下一年度资本利得。

例如：

2021：

亏损 20,000 元。

2022：

盈利 50,000 元。

V1：

2022 应税资本利得

=

50,000 元。

说明：

如用户需特殊处理，应咨询专业税务顾问。

---

# 12. 总补税金额

公式：

预计补税

=

股息利息补税

+

财产转让所得税

最低值：

0。

最终保留：

人民币两位小数。

四舍五入。

---

# 14. 示例

股息：

20,000 元。

利息：

500 元。

资本利得：

60,000 元。

境外预扣税：

2,000 元。

计算：

股息利息税额

=

20,500 × 20%

=

4,100 元。

可抵免税额

=

2,000 元。

股息利息补税

=

2,100 元。

资本利得税额

=

60,000 × 20%

=

12,000 元。

预计补税

=

14,100 元。

---

# 15. 边界情况

无交易流水：

仅计算股息利息税。

无股息收入：

仅计算资本利得税。

无应税收入：

预计补税为 0。

境外预扣税超过中国税额：

超出部分不退税。

资本亏损：

资本利得税为 0。

---

# 16. V1 最终原则

若存在多种解释，

按以下优先级执行：

1. 本文档规定；
2. 《中华人民共和国个人所得税法》；
3. 保守原则（避免低估应纳税所得额）；
4. 人工复核。

任何超出本文档范围的特殊情形，

系统应提示：

"发现 V1 未覆盖的税务场景，请人工确认。"

不得自动推断。
