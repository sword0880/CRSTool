\# 富途 Excel 字段映射规范（V1.0）



\## 文档目的



本文档用于定义富途证券导出 Excel 文件与系统内部数据模型之间的映射关系。



目标：



\* 固定 V1 支持的数据格式；

\* 避免因富途导出格式变化导致解析错误；

\* 为解析器开发和自动化测试提供依据。



适用范围：



\* 富途证券导出的股息税表；

\* 富途证券导出的年度交易流水。



\---



\# 1. 总体原则



V1 版本采用严格模式。



即：



\* Excel 模板固定；

\* 必须包含全部必填字段；

\* 字段名称必须完全匹配；

\* 字段顺序允许变化；

\* 存在额外字段时自动忽略。



若校验失败：



系统终止计算并提示用户。



例如：



"交易流水缺少字段：成交价格"



\---



\# 2. 内部数据模型



系统统一采用以下内部字段。



\## 2.1 股息利息模型



DividendIncomeRecord



| 内部字段          | 类型      | 说明                    |

| ------------- | ------- | --------------------- |

| account\_name   | string  | 账户名称                  |

| account\_no     | string  | 账户号码（如有）              |

| year           | int     | 税款所属年度                |

| dividend       | decimal | 全年股息收入（原币）           |

| interest       | decimal | 全年利息收入（原币）           |

| other\_income   | decimal | 全年其他收入（原币，V1不参与计算） |

| currency       | string  | 币种（USD / HKD / CNY）  |



\---



\## 2.2 交易模型



TradeRecord



| 内部字段          | 类型      | 说明       |

| ------------- | ------- | -------- |

| trade\_date    | date    | 成交日期     |

| symbol        | string  | 证券代码     |

| security\_name | string  | 证券名称     |

| side          | string  | BUY/SELL |

| quantity      | decimal | 成交数量     |

| price         | decimal | 成交价格     |

| commission    | decimal | 手续费      |

| currency      | string  | 币种       |



\---



\# 3. 股息税表映射规范



文件示例：



2021股息.xlsx



用途：



用于计算：



\* 股息红利所得；

\* 利息所得；

\* 境外已缴税额。



\---



\## 3.1 必填字段

实际富途导出文件为账户级别年度汇总（非逐笔明细），字段映射如下：

| Excel 字段 | 内部字段         | 类型      | 必填 | 说明                  |
| --------- | ------------ | ------- | -- | ------------------- |
| 牛牛号      | niuniu\_id   | string  | 是  | 富途用户 ID             |
| 年份       | year         | int     | 是  | 税款所属年度              |
| 账户名称     | account\_name | string  | 是  | 账户显示名称              |
| 全年股息     | dividend     | decimal | 是  | 年度股息收入总额（原币）       |
| 全年利息     | interest     | decimal | 是  | 年度利息收入总额（原币）       |
| 全年其他收入   | other\_income | decimal | 是  | 年度其他收入总额（原币，V1不参与） |
| 币种       | currency     | string  | 是  | 账户结算币种              |

注意：V1 版本使用汇总数据直接计算，不解析逐笔派发明细。



\---



\## 3.2 类型映射



Excel 值：



Dividend



映射：



DIVIDEND



含义：



股息红利所得。



\---



Excel 值：



Interest



映射：



INTEREST



含义：



利息所得。



\---



其他值：



系统报错。



错误示例：



"无法识别的收益类型：Capital Return"



\---



\## 3.3 日期处理



支持格式：



yyyy-MM-dd



yyyy/MM/dd



yyyyMMdd



统一转换为：



YYYY-MM-DD



例如：



2021/03/15



转换为：



2021-03-15



\---



\## 3.4 金额处理



收入金额：



必须大于等于 0。



预扣税：



允许为空。



为空时：



自动赋值为 0。



负数：



报错。



错误示例：



"收入金额不能为负数。"



\---



\## 3.5 币种处理



支持：



USD



HKD



不区分大小写。



统一转换：



USD



HKD



其他币种：



报错。



错误示例：



"暂不支持币种：SGD"



\---



\# 4. 交易流水映射规范



文件示例：



2021\_717110.xlsx



用途：



用于计算资本利得。



\---



\## 4.1 必填字段

| Excel 实际列名 | 内部字段          | 类型      | 必填 | 说明                     |
| ---------- | ------------- | ------- | -- | ---------------------- |
| 成交时间       | trade\_date   | date    | 是  | 格式：YYYY-MM-DD HH:MM:SS |
| 品类         | category      | string  | 是  | 证券 / 基金（用于过滤）        |
| 代码名称       | symbol        | string  | 是  | 股票代码                   |
| 方向         | side          | string  | 是  | 见方向映射表                 |
| 数量/面值      | quantity      | decimal | 是  | 买入为正，卖出为负（取绝对值）      |
| 价格         | price         | decimal | 是  | 成交单价                   |
| 总费用        | commission    | decimal | 否  | 佣金 + 平台费 + 交易征费等     |
| 币种         | currency      | string  | 是  | USD / HKD / CNY        |

额外保留字段（非必填，用于辅助分析）：

| Excel 实际列名 | 内部字段          | 类型      | 说明        |
| ---------- | ------------- | ------- | --------- |
| 账户名称       | account\_name | string  | 账户显示名称    |
| 账户号码       | account\_no   | string  | 完整账户号码    |
| 交易所/市场     | market        | string  | US / SEHK  |
| 交收日期       | settle\_date  | date    | 交收日期      |
| 成交金额       | trade\_amount | decimal | 成交金额      |
| 变动金额       | net\_amount   | decimal | 成交金额 − 总费用 |



\---



\## 4.2 买卖方向映射

Excel 实际值与内部映射：

| Excel 实际值 | 内部字段值 | 含义   |
| --------- | ----- | ---- |
| 买入开仓      | BUY   | 买入证券 |
| 卖出平仓      | SELL  | 卖出证券 |

兼容值：

| Excel 值 | 映射   |
| ------- | ---- |
| 买入       | BUY  |
| 卖出       | SELL |
| BUY      | BUY  |
| SELL     | SELL |

其他值（如"申购"、"赎回"）在品类过滤阶段已排除，不会进入方向映射。



\---



其他值：



报错。



错误示例：



"无法识别的买卖方向：TRANSFER"



\---



\## 4.3 成交数量

实际数据中，买入数量为正数，卖出数量为负数。

处理规则：

* 解析时统一取绝对值；
* 内部存储为正数。

支持：

* 整数；
* 小数（兼容碎股）。

错误示例：

"成交数量不能为 0。"



\---



\## 4.4 成交价格



要求：



必须大于 0。



错误示例：



"成交价格必须大于 0。"



\---



\## 4.5 手续费



允许为空。



为空时：



自动赋值为 0。



要求：



不得为负数。



\---



\# 5. 数据清洗规则



解析完成后执行标准化。



\## 字符串处理



自动：



\* 去除前后空格；

\* 转换全角空格；

\* 大写化币种；

\* 大写化证券代码。



例如：



aapl



转换：



AAPL



\---



\## 缺失值处理



手续费：



NULL → 0。



预扣税：



NULL → 0。



证券名称：



允许为空。



\---



\## 重复记录处理



V1 不自动去重。



即：



Excel 中每一行均视为有效记录。



如存在重复数据：



由用户自行确认。



\---



\# 6. 校验规则



股息税表：



必须至少存在一条记录。



交易流水：



允许为空。



说明：



若当年仅存在股息收入，



系统仅计算股息利息税额。



\---



交易流水中：



SELL 数量不得超过历史 BUY 库存。



否则：



终止计算。



错误示例：



"证券 AAPL 于 2021-08-20 卖出数量超过持仓数量。"



\---



\# 7. 解析输出示例



股息税表（账户级年度汇总）：



输入（Excel 原始数据）：

| 牛牛号   | 年份  | 账户名称     | 全年股息 | 全年利息 | 全年其他收入 | 币种  |
| ------- | --- | ---------- | ------ | ------ | ---------- | --- |
| 7171103 | 2021 | 港股融資帳戶 | 82.45  | 0.00   | 0.00       | HKD |



输出：

```json
{
  "account_name": "港股融資帳戶",
  "year": 2021,
  "dividend": 82.45,
  "interest": 0.00,
  "other_income": 0.00,
  "currency": "HKD"
}
```



\---



交易流水：



输入（Excel 原始数据）：

| 成交时间            | 品类 | 代码名称 | 方向     | 数量/面值 | 价格  | 总费用 | 币种  |
| ----------------- | --- | ------- | ------- | ------- | ---- | ---- | --- |
| 2021-08-20 10:30:00 | 证券 | AAPL    | 卖出平仓  | -100    | 150  | 1    | USD |



输出：

```json
{
  "source_row": 42,
  "trade_date": "2021-08-20",
  "category": "证券",
  "symbol": "AAPL",
  "side": "SELL",
  "quantity": 100,
  "price": 150,
  "commission": 1,
  "currency": "USD"
}
```

注意：数量原始值为 -100，解析后取绝对值为 100。



\---



\# 8. V1 边界说明



支持：



\* 美股普通股；

\* 港股普通股；

\* 美股碎股；

\* 现金利息；

\* 富途固定模板。



不支持：



\* 期权；

\* 期货；

\* ETF 特殊分配；

\* DRIP 自动分红再投资；

\* 股票拆分与合股；

\* 转仓；

\* 融资融券；

\* 公司行动导致的成本调整。



上述场景若出现在 Excel 中，系统应提示：



"发现 V1 暂不支持的交易类型，请人工处理。"
