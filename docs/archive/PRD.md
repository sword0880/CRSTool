# 富途海外证券个税助手（中国税务居民版）PRD V1.0

## 1. 项目背景

中国税务居民持有海外证券账户（如富途证券）后，需要对境外取得的股息、利息、财产转让所得依法申报个人所得税。

目前缺少简单易用的辅助工具。

本项目目标是：

导入富途导出的固定格式 Excel，自动计算年度境外所得，并输出个人所得税辅助测算结果。

---

# 2. 产品定位

产品名称：

富途海外证券个税助手

目标用户：

* 中国税务居民个人；
* 使用富途证券投资海外证券；
* 需要测算境外所得个人所得税。

产品目标：

让用户在 5 分钟内完成年度境外所得税额测算。

---

# 3. MVP 范围

支持：

* 富途固定格式 Excel 导入；
* 股息收入计算；
* 利息收入计算；
* 境外预扣税抵免；
* 股票资本利得计算；
* FIFO 成本法；
* 中国个人所得税测算；
* Excel 导出。

不支持：

* 多券商；
* 自动申报；
* 融资融券；
* 期权、期货、窝轮；
* 自动联网汇率；
* 多税务居民身份；
* 企业用户。

# 5. 输入文件要求

## 5.1 股息税表

文件示例：

* 2021股息.xlsx（Excel 格式）
* 2025_7171103.pdf（PDF 格式）

支持格式：`.xlsx` 和 `.pdf`。

### PDF 格式说明

PDF 文件为富途导出的税务报表，包含与 Excel 版本相同的表格数据：

* 账户信息（姓名、牛牛号、账户名称、年份）
* 股息利息及其他收入明细（牛牛号、年份、账户名称、全年股息、全年利息、全年其他收入、币种）
* 参考汇率表（系统忽略）

系统使用 `pdfplumber` 自动识别并提取表格数据，字段含义和计算逻辑与 Excel 版本完全一致。

### Excel 格式说明

固定格式，包含 3 个 Sheet：

### Sheet 1：账户信息

| 字段   | 说明          |
| ---- | ----------- |
| 姓名   | 用户姓名        |
| 牛牛号  | 富途用户 ID     |
| 账户名称 | 账户显示名称      |
| 年份   | 税款所属年度      |

### Sheet 2：股息、利息及其他收入

该表为**账户级别年度汇总**，非逐笔明细。

| 字段       | 说明                       |
| -------- | ------------------------ |
| 牛牛号      | 富途用户 ID                  |
| 年份       | 税款所属年度                   |
| 账户名称     | 账户显示名称                   |
| 全年股息     | 该账户年度股息收入总额（原币）        |
| 全年利息     | 该账户年度利息收入总额（原币）        |
| 全年其他收入   | 该账户年度其他收入总额（原币）        |
| 币种       | 账户结算币种（USD / HKD / CNY） |

说明：

* 每行代表一个账户的年度汇总，不是逐笔派发记录；
* 全年股息对应股息红利所得；
* 全年利息对应利息所得；
* 全年其他收入暂不计入 V1 计算，仅展示；
* 所有数值为文本格式，解析时需转换为 Decimal。

### Sheet 3：参考汇率

富途提供的香港税务局（IRD）年度平均汇率参考表。

| 字段         | 说明                           |
| ---------- | ---------------------------- |
| USD Dollar | 1 USD = N HKD                |
| 其他币种      | 各外币兑 HKD 年度平均汇率            |
| Renminbi   | 100 HKD = N CNY（人民币兑港币汇率） |

说明：

* 该汇率表为参考数据，系统实际使用内置的 `exchange_rate.json` 进行换算；
* 若用户需要使用 IRD 参考汇率，可手动更新配置文件。

* 数据类型正确；
* 无法识别时提示错误。

错误示例：

“交易流水缺少【价格】字段。”

---

## 6.2 交易数据过滤与方向映射

### 品类过滤

交易流水（证券-交易流水 Sheet）中包含证券和基金两种品类：

| 品类值 | 处理方式           |
| --- | -------------- |
| 证券  | 正常解析，进入计算流程   |
| 基金  | 跳过，不计入资本利得计算  |

基金交易方向为”申购”和”赎回”，与证券的”买入开仓”和”卖出平仓”不同。

提示信息：

“检测到 N 条基金交易记录，已跳过。V1 暂不支持基金收益计算。”

### 买卖方向映射

Excel 中”方向”字段的实际值与内部映射：

| Excel 实际值 | 内部字段值 | 含义   |
| --------- | ----- | ---- |
| 买入开仓      | BUY   | 买入证券 |
| 卖出平仓      | SELL  | 卖出证券 |

兼容值：

| Excel 值 | 映射   |
| ------- | ---- |
| 买入       | BUY  |
| 卖出       | SELL |
| BUY      | BUY  |
| SELL     | SELL |

其他值（如”申购”、”赎回”）在品类过滤阶段已排除，不会进入方向映射。

### 数量符号处理

实际数据中，卖出数量为负数。系统在解析时统一取绝对值：

* 买入开仓：数量为正数 → 直接使用；
* 卖出平仓：数量为负数 → 取绝对值后使用。

错误示例：

“无法识别的买卖方向：TRANSFER”

## 6.4 汇率处理

V1 采用系统内置年度平均汇率。

配置方式：

exchange_rate.json

示例：

```json
{
  "2021": {
    "USD": 6.4515,
    "HKD": 0.8291
  }
}
```

转换规则：

人民币金额 = 原币金额 × 年度平均汇率。

币种来源说明：

| 收入类型   | 原币币种来源              | 转换逻辑                  |
| ------ | ------------------- | --------------------- |
| 股息收入   | 股息表"币种"列（HKD/USD） | 原币 × 对应币种年度平均汇率 → 人民币 |
| 利息收入   | 股息表"币种"列（HKD/USD） | 原币 × 对应币种年度平均汇率 → 人民币 |
| 资本利得   | 交易流水"币种"列           | 原币 × 对应币种年度平均汇率 → 人民币 |
| 境外预扣税  | 资金进出 Sheet 备注中的币种  | 原币 × 对应币种年度平均汇率 → 人民币 |

注意事项：

* 股息表中的金额已是账户结算币种（非统一币种），需按各行币种分别换算；
* 避免双重换算：不要将 HKD 金额先换 USD 再换 CNY；
* 若币种为 CNY，无需换算，直接使用原值。

## 6.5 资本利得计算

采用 FIFO（先进先出）。

买入：

进入库存。

卖出：

按最早买入记录依次匹配。

排序规则：

交易记录按 `成交日期 ASC, 原始行号 ASC` 排序，保证同日交易顺序与 Excel 一致。

原始行号（source_row）：

解析时记录每条交易在 Excel 中的原始行号，用于 FIFO 排序稳定性。

计算公式：

收益 = 卖出收入 − 卖出手续费分摊 − 买入成本 − 买入手续费分摊

手续费分摊规则：

当一笔卖出跨越多笔 FIFO 库存时，手续费按卖出数量比例分摊。

示例：

* 卖出 150 股，手续费 3 元；
* 匹配库存 A（100 股）和库存 B（50 股）；
* 库存 A 分摊手续费 = 3 × (100/150) = 2；
* 库存 B 分摊手续费 = 3 × (50/150) = 1。

买入手续费同理：当一笔买入被多笔卖出部分匹配时，买入手续费按匹配数量比例分摊。

输出：

每笔卖出对应：

* 匹配买入记录；
* 成本；
* 收入；
* 买入手续费分摊；
* 卖出手续费分摊；
* 收益。

### 股票更名处理

系统从交易流水文件的"证券-资产进出"Sheet 读取股票更名记录。

识别规则：

* 备注字段包含"SYMBOL CHANGE"关键字；
* 同一日期存在一对 In/Out 记录；
* In 记录的新代码与 Out 记录的旧代码构成映射关系。

处理方式：

* 自动将旧代码的所有买入记录映射到新代码名下；
* FIFO 匹配时，旧代码的库存可用于新代码的卖出匹配；
* 映射关系在计算过程中生效，不修改原始数据。

示例：

INAQ 于 2021-02-09 更名为 MILE → 系统将 INAQ 的买入记录自动归入 MILE 库存。

提示信息：

"检测到股票更名：INAQ → MILE（2021-02-09），已自动关联。"

不支持的公司行动：

* 股票拆分与合股；
* 成本调整；
* 其他复杂公司行动。

上述场景若出现在资产进出记录中，系统应提示：

"发现 V1 暂不支持的公司行动类型（拆分/合股），请人工处理相关持仓。"

### 赠送股票处理

从"证券-资产进出"Sheet 识别"Gift Stock"记录。

处理方式：

* 接收赠送的股票以 0 成本计入 FIFO 库存；
* 卖出时，成本按 0 计算，全部卖出收入计入资本利得；
* 提示用户确认："检测到赠送股票 9988 × 1 股，成本按 0 处理，是否继续？"

### 跨年度持仓处理

当卖出记录的股票在当年买入记录中无匹配库存时（即年末持仓在年初已存在），系统按以下优先级处理：

1. 优先从"证券-持仓总览"Sheet 读取期初持仓数据，作为 FIFO 初始库存：
   * 筛选 `时期类型 = 期初` 的记录；
   * 按 `代码名称` 和 `币种` 建立初始库存；
   * 成本按期初 `价格` 计算。

2. 若期初持仓中无对应股票，提示用户：

   "证券 XXX 存在跨年度卖出，请导入包含该股票历史买入的完整交易流水。"

3. 若用户选择仅导入单年数据且无期初持仓匹配，该卖出记录标记为"待人工确认"，不参与自动计算。

## 6.6 个税测算

### 股息及利息所得

税率：

20%。

公式：

# 中国应纳税额

（股息 + 利息）×20%。

抵免：

境外已缴税额可抵免。

抵免上限：

不超过对应所得中国应纳税额。

补税：

中国税额 − 可抵免税额。

---

### 财产转让所得

税率：

20%。

公式：

资本利得 ×20%。

不与股息税额混抵。

---

## 6.7 境外预扣税提取

境外已缴税额（预扣税）从交易流水文件的"证券-资金进出"Sheet 中提取。

识别规则：

* 备注字段包含"Withholding Tax"关键字；
* 变动金额为负数（资金流出）；
* 币种从备注文本中解析，格式如"USD PER SHARE"。

提取逻辑：

1. 遍历"证券-资金进出"Sheet 所有记录；
2. 筛选备注中包含"Withholding Tax"的行；
3. 取变动金额的绝对值作为预扣税金额；
4. 币种取该行的"币种"字段；
5. 按币种汇总，得到各币种的境外已缴税额合计。

示例：

备注："AAPL 2.00000000 Shares Withholding Tax -0.022 USD PER SHARE- TAX"

→ 预扣税金额 = 0.022，币种 = USD

生成单个 Excel 文件 `Tax_Report.xlsx`，包含 4 个 Sheet。

## 7.1 Sheet 1：税务汇总

| ------ | ------- |
| 股息收入   |         |
| 利息收入   |         |
| 资本利得   |         |
| 股息利息税额 |         |
| 资本利得税额 |         |
| 抵免税额   |         |
| 预计补税   |         |

## 7.2 Sheet 2：资本利得汇总

按股票代码汇总当年盈利金额，按收益从高到低排序。

| 股票代码 | 交易笔数 | 币种 | 收益（原币） | 收益（人民币） |
| ---- | ---- | -- | ------- | ------- |

## 7.3 Sheet 3：资本利得明细

每笔 FIFO 匹配的详细记录。

| 证券代码 | 卖出日期 | 卖出数量 | 买入日期 | 匹配成本 | 收入 | 买入手续费 | 卖出手续费 | 币种 | 收益（原币） | 收益（人民币） |
| ---- | ---- | ---- | ---- | ---- | -- | ----- | ----- | -- | ------- | ------- |

字段说明：

| 字段       | 说明                         |
| -------- | -------------------------- |
| 证券代码     | 股票代码                       |
| 卖出日期     | 卖出交易日期                     |
| 卖出数量     | 本次卖出数量                     |
| 买入日期     | FIFO 匹配到的最早买入日期           |
| 匹配成本     | 对应买入的总成本（价格 × 数量）        |
| 收入       | 卖出总收入（价格 × 数量）            |
| 买入手续费    | 对应买入交易的手续费                 |
| 卖出手续费    | 本次卖出交易的手续费                 |
| 币种       | 交易币种（USD / HKD）            |
| 收益（原币）  | 收入 − 匹配成本 − 买入手续费 − 卖出手续费 |
| 收益（人民币） | 原币收益 × 年度平均汇率              |

用于留档和核对。

## 7.4 Sheet 4：入金汇总

从交易流水文件的"证券-资金进出"Sheet 中提取入金记录（方向=In，类型=出入金）。

按币种汇总：

| 币种 | 入金笔数 | 入金总额 |
| -- | ---- | ---- |

明细：

| 日期 | 账户名称 | 币种 | 入金金额 |
| -- | ---- | -- | ---- |

| currency     | string  | 币种                    |

FIFO 匹配记录（资本利得明细）。

| 字段                    | 类型      | 说明                                    |
| --------------------- | ------- | ------------------------------------- |
| symbol                | string  | 股票代码                                  |
| sell_date             | date    | 卖出日期                                  |

| buy_date              | date    | 匹配买入日期                                |

# 9. 非功能需求

运行方式：

本地运行。

技术方案：

Python + Streamlit。

性能要求：

交易流水 10,000 条以内，

计算时间不超过 5 秒。

数据安全：

* 所有数据本地处理；
* 不上传服务器；
* 不联网。

## 9.1 UI 消息策略

系统消息分为三个级别：

| 级别       | Streamlit 方法   | 用途           | 示例                    |
| -------- | -------------- | ------------ | --------------------- |
| 错误（阻断）  | `st.error()`   | 校验失败，终止计算  | "交易流水缺少【价格】字段"     |
| 警告（不阻断） | `st.warning()` | 发现需注意的情况   | "检测到 22 条基金交易记录，已跳过" |
| 信息       | `st.info()`    | 计算过程中的状态提示 | "检测到股票更名：INAQ → MILE" |

消息累积规则：

* 错误消息立即显示，终止后续流程；
* 警告和信息消息在计算完成后统一展示在结果页顶部；
* 消息格式统一为：`[级别] 消息内容`。

---

## 9.2 汇率配置异常处理

当 `exchange_rate.json` 中缺少对应年份或币种时：

* 系统报错并终止计算；
* 提示信息："配置文件中缺少 {year} 年 {currency} 的汇率，请补充 exchange_rate.json"。

CNY 币种特殊处理：

* 若汇率配置中未包含 CNY，系统默认 CNY 汇率为 1.0000；
* 不报错。

---

## 9.3 金额精度规则

所有财务计算使用 Python `decimal.Decimal` 类型：

* 从 Excel 读取的浮点数先转为字符串，再转为 Decimal；
* 中间计算保留 8 位小数；
* 最终输出保留 2 位小数，四舍五入（ROUND_HALF_UP）。

---

## 9.4 参考汇率 Sheet 处理

股息表中的"参考汇率"Sheet（IRD 汇率表）：

* 不参与系统计算；
* 不展示给用户；
* 解析时直接忽略。

---

## 9.5 "全年其他收入"展示规则

股息表中"全年其他收入"字段：

* 不计入税额计算；
* 在结果页的股息利息明细表中单独列示；
* 导出 Excel 中包含该字段，标注"仅供参考，未计入计算"。

兼容性：

Windows 10/11。
