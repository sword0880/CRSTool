# FIFO 计算实现约定

描述 [FifoEngine](../src/CRS.Domain/FIFO/FifoEngine.cs) 当前行为及 [尚待验收的问题](KNOWN_ISSUES.md)。

## 身份、排序与范围

库存以 SecurityKey 隔离：账户、证券身份、币种、券商、市场。代码仅用于展示，不能作为跨账户库存合并依据。

成交与快照共用 FifoOrdering：成交时间、完整证券身份、来源文件、来源行序、记录编号及完整金额字段依次稳定排序。期初 LOT 也按时间、身份及完整批次字段稳定排序。同一证券混用有／无时区记录会拒绝。

同证券同一时间的跨文件成交、同文件相同行序，以及同时刻的多个期初 LOT 不能由输入排列证明先后，产生 AMBIGUOUS_FIFO_ORDER 并隔离相关成本。文件名和编号的排序仅保证可重复，不充当真实成交顺序的证据。

历史交易可以参与成本链，仅目标年度卖出匹配进入年度收益。支持范围以券商解析器为准；未知公司行动和转仓不会自动补成本。

## 金额与费用

Trade.Gross 是规范化成交总额，Fee 是费用；价格乘数量是解析阶段核对依据。CostLot.CostBasisMode 明确本金加费用、已含费用总成本或未知口径。

- PrincipalPlusFees：唯一可扣成本为 Cost + Fee。
- TotalCostIncludesFees：唯一可扣成本为 Cost，Fee 仅披露，不再次扣除。
- Unknown：不能计算总成本。

买入成本、费用与卖出金额按数量分摊并累计舍入，保留末笔余差。Money 使用 decimal.Round(value, 2, AwayFromZero)。Match.Cost 已是分摊总成本，Gain = Revenue - SellFee - Cost；不能再减 BuyFee。

富途持仓市价不充当真实成本。缺成本或库存不足产生 MISSING_COST，后续买入不自动修复受影响库存；独立证券仍可计算，未知收益留空。

## 示例与限制

买入 100@100、费用 2，卖出 100@150、费用 2，收益为 4,996。卖出 40 股且卖出费用 2，收益为 1,997.20。

买入 A 为 100@100、费用 2，B 为 100@120、费用 2；卖出 150@150、费用 3。收入 22,500，总成本 16,003，卖出费 3，收益 6,494。

跨年结转仅在结果门槛允许时导出；旧格式兼容与严格复算仍未验收。测试、证券事件和真实成本来源的业务签认分别保留，不能用示例替代。
