\# 资本利得计算规则说明（FIFO 实现规范）V1.0



\## 1. 文档目的



本文档用于规范资本利得（财产转让所得）的计算逻辑。



目标：



\* 固化 FIFO（先进先出）算法；

\* 确保同一份交易数据计算结果唯一；

\* 为开发、测试、审计提供统一依据；

\* 作为税务底稿生成依据。



适用范围：



\* 富途证券年度交易流水；

\* 中国税务居民个人境外证券所得测算。



\---



\# 2. 适用范围



V1 支持：



\* 美股普通股；

\* 港股普通股；

\* 碎股交易；

\* 跨年度持仓；

\* 多次买入、多次卖出。



V1 不支持：



\* 卖空（Short）；

\* 融资融券；

\* 期权；

\* 期货；

\* ETF 特殊分配；

\* 转仓；

\* 公司行动导致成本变化；

\* 股票拆分与合股；

\* DRIP 自动分红再投资。



发现上述交易时：



终止计算。



提示：



"发现暂不支持的交易类型，请人工处理。"



\---



\# 3. 基本原则



资本利得采用：



FIFO（First In First Out）



即：



最早买入的股票，

最早作为卖出成本。



原则：



同一证券代码独立计算。



例如：



AAPL 与 TSLA 分别维护库存。



不得混用。



\---



\# 4. 数据准备



解析完成后：



交易记录按以下顺序排序：



第一排序：



成交日期升序。



第二排序：



Excel 原始行号升序。



即：



trade\_date ASC

row\_number ASC



目的：



保证结果稳定。



\---



\# 5. 库存模型



每个证券维护独立库存队列。



库存单元：



Lot



字段：



| 字段                   | 说明    |

| -------------------- | ----- |

| buy\_date             | 买入日期  |

| quantity\_remaining   | 剩余数量  |

| price                | 买入价格  |

| commission\_remaining | 剩余手续费 |

| currency             | 币种    |

| source\_row           | 原始行号  |



库存结构：



Queue<Lot>



FIFO：



先进先出。



\---



\# 6. 买入规则



买入方向：



BUY。



处理方式：



创建库存批次（Lot）。



加入队列尾部。



计算：



\# 买入总成本



成交数量 × 成交价格

\+

手续费



示例：



2021-01-10



买入：



100股



价格：



100 USD



手续费：



2 USD



生成：



Lot：



数量：



100



成本：



10002 USD



\---



\# 7. 卖出规则



卖出方向：



SELL。



处理方式：



从库存头部开始匹配。



直到卖出数量全部匹配完成。



匹配顺序：



最早买入

↓

次早买入

↓

依次递减库存。



\---



\# 8. 成本分摊规则



若卖出数量小于库存批次数量：



按比例分摊买入手续费。



公式：



分摊买入手续费



=

原买入手续费

×

（匹配数量 ÷ 原买入数量）



例如：



买入：



100股



手续费：



2 USD



卖出：



40股



分摊手续费：



2 × 40 ÷ 100



=

0.8 USD



剩余：



1.2 USD



继续保留库存。



\---



\# 9. 卖出手续费处理



卖出手续费全部计入本次卖出。



公式：



卖出净收入



=

卖出金额

−卖出手续费



其中：



卖出金额



=

卖出数量 × 卖出价格



\---



\# 10. 财产转让所得计算



每次匹配形成一个 Match。



公式：



收益



=

卖出收入

−卖出手续费分摊

−买入成本

−买入手续费分摊



即：



收益



=

（卖出数量×卖出价格）

−卖出手续费分摊

−（买入数量×买入价格）

−买入手续费分摊



\---



\# 11. Match 模型



每个 Match 保存：



| 字段               | 说明      |

| ---------------- | ------- |

| symbol           | 证券代码    |

| sell\_date        | 卖出日期    |

| buy\_date         | 匹配买入日期  |

| matched\_quantity | 匹配数量    |

| buy\_price        | 买入价格    |

| sell\_price       | 卖出价格    |

| buy\_commission   | 分摊买入手续费 |

| sell\_commission  | 分摊卖出手续费 |

用于：



税务底稿生成。

\# 15. 库存不足处理



卖出数量



>



库存数量。



例如：



库存：



100股。



卖出：



150股。



处理：



终止计算。



报错：



"AAPL 于 2021-08-20 卖出数量超过持仓数量。"



不得自动补零。



不得允许负库存。



\---



\# 16. 年度计算规则



支持跨年度持仓。



即：



上一年度未卖出的库存，



自动结转至下一年度。



例如：



2020 买入。



2021 卖出。



允许匹配。



若仅导入单年度交易流水：



系统无法恢复历史库存。



提示：



"发现跨年度卖出，请导入完整历史交易流水。"



\---



\# 17. 损益汇总规则



年度资本利得



=



所有 Match 收益求和。



公式：



Annual Gain



=



Σ Match Gain



允许负数。



即：



亏损年度输出负值。



例如：



\-5,000 CNY



仍生成税务底稿。



\---



\# 18. 人民币换算规则



V1：



采用年度平均汇率。



换算时点：



Match 收益计算完成后。



公式：



人民币收益



=



美元收益 × 年度平均汇率



港币收益 × 港币平均汇率



最终：



年度资本利得（人民币）



=



所有人民币 Match 收益求和。
