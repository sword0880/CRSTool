# 输入示例

- [账户期间清单](account-periods.example.json)：在导入页选择，必须填入实际账户、日期和凭证，并在人工核对后确认。
- [抵免明细模板](../../tests/templates/foreign-credit.example.json)：说明见[抵免复核](../guides/FOREIGN_CREDIT_REVIEW.md)。
- [真实金额验收模板](../../tests/templates/real-sample.example.json)：说明见[发布验收](../validation/RELEASE_ACCEPTANCE.md)。

示例不含真实账户资料；占位值及默认未核对状态不能作为业务签认。后两份模板保留在 tests/templates，由验收工具共同维护，避免复制后版本不一致。
