# CRS Tax Manager 产品说明

更新日期：2026-10-10。本文描述当前 WPF 产品范围；原始富途／Python 需求保存在 [历史基线](archive/PRD.md)。

## 用户与目标

为需要核对境外证券所得的个人提供本地辅助测算、来源追踪和 Excel 底稿。支持 IBKR Activity Flex XML 与已验收布局的富途交易／年度收入文件。当前规则版本为 V1-2026-09；不将辅助结果等同于已完成业务签认的申报金额。

## 当前流程

1. 在“数据导入”选择券商、年度和活动文件。
2. 提供期初 LOT XML（IBKR）或 C# 结转 JSON，或者确认期初无持仓；确认导出范围没有过滤。
3. 可选择保存完整规范化输入快照；默认不持久化原始交易明细。
4. 计算后查看税务、FIFO、交易、对账与待复核问题；资料不足时保留未知状态。
5. 记录人工依据，导出 Excel；年末成本满足门槛时才能导出结转。
6. 从历史任务恢复冻结结果。历史恢复不自动重新计算或改变原税额。

概览使用真实任务和当前结果；初次启动不显示演示数量。输入改变会清除旧结果、图表、复核依据及导出资格。

## 页面与组件

九个页面：概览、数据导入、交易记录、FIFO 计算、汇率管理、税务核算、核对、报表导出、历史任务。WPF UI 4.3.x 提供导航，CommunityToolkit.Mvvm 管理展示状态，DataGridExtensions 提供列筛选，LiveCharts 展示已计算结果。尚未接入行情服务。

WPF 只处理展示和交互；金额、成本、状态判定、持久化、解析和输出由后台负责。Python 与 WinForms 项目已删除。

## 支持范围与限制

- IBKR：本地 Activity Flex XML、多文件／多账户、ID 冲突校验、现金／收益／持仓对账；可选联网下载。
- 富途：年度交易 XLSX、收入 XLSX／已支持的文本 PDF、资金及证券事件记录。只有收入时保留缺交易／税款资料提示。
- 原币、数量和汇率使用 decimal；未知值为空，不当作零。
- 复杂公司行动、转仓成本、做空、衍生品及 IBKR CSV／PDF 尚未支持。
- 多账户年度聚合后台已有辅助算法，WPF 尚无跨运行选择与聚合入口。
- 完整历史复算、旧结转转换和抵免证据门槛尚未闭环。

## 数据与验收

SQLite 沿用 %LOCALAPPDATA%/CRS.WinForms/crs.db，仅保留旧目录名兼容存量数据。Flex 令牌只保留在当前窗口，不写配置、底稿和日志。完整快照包含规范化业务记录，保存前由用户选择。

性能、测试覆盖率和真实全年业务签认不因构建通过而视为达标。实际验证入口见 [测试规范](TEST_SPEC.md)，支持的文件布局见两份券商指南。
