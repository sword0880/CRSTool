# 境外证券投资所得税辅助计算工具 — 产品说明

产品正式名称为“境外证券投资所得税辅助计算工具”，项目标识为 CRS。WPF 是唯一前台，面向个人提供本地所得辅助计算、来源核对和 Excel 底稿，不自动申报。当前支持 IBKR Activity Flex XML 与已支持布局的富途 XLSX／文本 PDF。

## 界面

九个业务页面：概览、数据导入、交易记录、FIFO、汇率、税务、核对、导出和历史。左侧菜单可折叠，折叠后只保留图标；右上角提供设置和关闭。设置窗口管理日志与数据库，下次启动生效。

概览显示真实任务与当前结果。WPF UI 4.3.x、CommunityToolkit.Mvvm、DataGridExtensions 和 LiveCharts 提供导航、状态、表格及结果图表；尚未接入行情服务。

## 导入与结果

IBKR 可选择多份活动 XML；富途分别选择股息收入主表和交易明细。两类富途文件可以独立替换或清除；取消选择保留原文件，替换或清除使旧结果失效。交易文件可包含连续的历史年度。只有收入文件时仍可辅助计算，但保留缺交易和扣税资料提示。

期初需要真实 LOT 成本、C# 结转或实际无持仓确认，不能使用市价替代。选择年度并确认报告未过滤范围后，后台统一导入、计算和核对。

未知金额为空，不伪造零。人工依据不改变原税额或自动解除成本问题。Excel 底稿和结转导出受后台状态门槛控制。

## 历史与隐私

默认存储结果和笔数，原始交易留在当前会话；用户选择完整规范化快照后可从历史恢复交易。历史页恢复冻结结果，不自动重算。完整快照包含敏感业务数据，Flex 令牌不持久化。

本机目录设置见 [设置说明](SETTINGS.md)。现有辅助规则及未完成验收见 [当前问题](KNOWN_ISSUES.md)。

## 数据安全及产品演进（规划）

**当前产品事实：** 仍为无独立解锁密码的本地 WPF 程序；SQLite 数据库和普通 Excel 导出未加密。即使默认不持久化 SessionTrades，历史结果、账户与税务记录也包含个人敏感数据，详见 [PRIVACY.md](PRIVACY.md)。本节均为**待开发的产品需求**。架构已确定引入独立 `CRS.Security`（第五个生产项目），具体职责与依赖见 [SAD.md](SAD.md)；当前尚未创建该项目。

### V1.0：单用户离线安全加固

1. **首次初始化：** 用户创建或恢复本地数据保险库，设置独立主密码，并确认保存恢复密钥；不要求注册网络账号。
2. **启动访问：** 需要主密码解锁保险库；检测到旧明文 SQLite 立即提示不支持并拒绝读取。密码错误、数据损坏、格式不支持必须明确报错，不允许自动使用明文后备库。
3. **自动锁定：** 默认无操作 10 分钟、Windows 锁屏/休眠后锁定，锁定期间不能查看历史、交易与税务结果或继续后台写入。
4. **密码与恢复：** 支持修改主密码，凭独立恢复密钥重新设密；丢失全部有效凭证时明确不可保证恢复。
5. **数据保护：** 本地 SQLite 采用 SQLCipher 加密，原件/缓存/日志的敏感数据处理纳入安全验收。
6. **备份恢复及重新创建：** 提供默认加密的离线备份及换电脑恢复；**不支持旧明文 SQLite 迁移**。发现旧明文库时保留原文件，仅允许用户选择新的空目录创建全新加密保险库；旧历史记录不会自动带入，必要时重新导入原始券商文件。
7. **普通导出：** 原有 Excel/结转业务门槛保持不变，明文导出给出明显风险提示。

### V1.5：面向其他投资者的桌面发行版

允许每个用户创建独立保险库，提供可选**加密导出**（仍支持主动选择的明文导出）、安装更新安全、数据兼容升级、许可证与隐私审查。公开发布前需完成安全验收和现有业务真实样本验收，不因界面可操作就宣称达到发布条件。

### V2.0 及以后：按需在线服务

只有出现多设备同步等真实需求时，才评估账号登录、授权及云端存储。**在线身份认证与本地数据库解锁必须分离**，用户离线计算的基本能力不依赖服务器。产品需求由 [SECURITY_DESIGN.md](SECURITY_DESIGN.md) 约束，待办追踪见 [KNOWN_ISSUES.md](KNOWN_ISSUES.md)。
