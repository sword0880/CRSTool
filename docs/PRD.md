# CRS Tax Manager 产品说明

WPF 是唯一前台。面向个人提供本地境外证券所得辅助测算、来源核对和 Excel 底稿，不自动申报。当前支持 IBKR Activity Flex XML 与已支持布局的富途 XLSX／文本 PDF。

## 界面

九个业务页面：概览、数据导入、交易记录、FIFO、汇率、税务、核对、导出和历史。左侧菜单可折叠，折叠后只保留图标；右上角提供设置和关闭。设置窗口管理日志与数据库，下次启动生效。

概览显示真实任务与当前结果。WPF UI 4.3.x、CommunityToolkit.Mvvm、DataGridExtensions 和 LiveCharts 提供导航、状态、表格及结果图表；尚未接入行情服务。

## 导入与结果

IBKR 可选择多份活动 XML；富途分别选择股息收入主表和交易明细。两类富途文件可以独立替换或清除；取消选择保留原文件，替换或清除使旧结果失效。交易文件可包含连续的历史年度。只有收入文件时仍可辅助计算，但保留缺交易和扣税资料提示。

期初需要真实 LOT 成本、C# 结转或实际无持仓确认，不能使用市价替代。选择年度并确认报告未过滤范围后，后台统一导入、计算和核对。

未知金额为空，不伪造零。人工依据不改变原税额或自动解除成本问题。Excel 底稿和结转导出受后台状态门槛控制。

## 历史与隐私

默认存储结果和笔数，原始交易留在当前会话；用户选择完整规范化快照后可从历史恢复交易。历史页恢复冻结结果，不自动重算。完整快照包含敏感业务数据，Flex 令牌不持久化。
