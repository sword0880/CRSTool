# 验证与验收规范

手机认证专项当前证据与人工缺口见 [AUTH_IMPLEMENTATION.md](AUTH_IMPLEMENTATION.md)：RFC6238 向量、首次绑定、受限会话、并发防重放、恢复码消费、换机取消、密码恢复强制绑定、时间回退、持久冷却和原有业务回归均有自动检查；手机实机、跨电脑及系统故障测试不得以合成检查替代。

本文列出当前可执行检查和验收边界；[未完成的工作](KNOWN_ISSUES.md)单独维护。

## 金额与状态的必查边界

- 一笔卖出匹配多批次、一笔买入分多次卖出，成本与费用守恒。
- 账户、券商、证券、市场、币种隔离；同卖出 ID 不串用成本。
- 缺成本、资料缺失和无法核对保持未知值，不伪造零值。
- 报告期间缺口、重复／冲突来源、未知证券事件进入对应门槛。
- 取消不保存半成品，输入变化清除旧结果和导出资格。
- 历史复算不读取当前汇率；无效历史元数据拒绝；跨年不自动升级临时状态。

## 算术与未知值边界

买入 100@100 与 100@120、各费用 2，卖出 150@150、费用 3，独立算术结果为 6,494。样例必须明确费用和成本口径，逐批次与总额都需要核对。

缺成本时记录 MISSING_COST、阻断受影响库存并允许独立证券继续计算，不能把未知收益补成零。
## 尚未完成的验收

真实全年成本及抵免证据、复杂事件、严格历史重放、旧结转转换、发布授权／隐私、耗时与内存基准仍需专项证据。尚无自动覆盖率报告，不宣称达到原提案中的 95%／90% 等目标。合成窗口检查不代替真实账户业务验收。

安全验证新增 CRS.Tests.Security 与 Infrastructure/VaultChecks：纯 KDF／封装、实际 SQLCipher、WAL、一致性加密备份、恢复、改密、旧会话和明文库拒绝；前台新增恢复确认与目录绑定门槛检查。详见 VAULT_GUIDE.md；真实硬件锁屏、跨设备恢复和发布审查不能由合成测试自动认定通过。
