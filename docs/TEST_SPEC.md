## 金额与状态的必查边界

- 一笔卖出匹配多批次、一笔买入分多次卖出，成本与费用守恒。
- 账户、券商、证券、市场、币种隔离；同卖出 ID 不串用成本。
- 缺成本、资料缺失和无法核对保持未知值，不伪造零值。
- 报告期间缺口、重复／冲突来源、未知证券事件进入对应门槛。
- 取消不保存半成品，输入变化清除旧结果和导出资格。
- 历史复算不读取当前汇率；无效历史元数据拒绝；跨年不自动升级临时状态。

## 已发现的旧示例问题

原 FIFO CASE-003 写入 7,494，且卖出收入分配公式有误。按原场景买入 100@100 与 100@120、各费用 2，卖出 150@150、费用 3，独立算术结果为 6,494。本次纠正文档示例，不据此声明旧 golden 已获业务签认。

缺成本的当前行为是记录 MISSING_COST、阻断受影响库存并允许独立证券继续计算；旧规范“任何库存不足均终止全部计算”不适用于当前实现。
