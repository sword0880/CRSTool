# 雪球观点追踪

从 **扩展工具 → 雪球观点追踪** 打开。需使用包含本插件的桌面与 Worker 版本，并以 Windows 管理员权限打开 CRS。首次运行预置九个观察账号，其中包括管我财、学知利行、达人知命和股市小民a，账号名称、备注、启用状态和移除均可在观察名单中设置。

「录入 / 导入资料」支持手工笔记和有权处理的 UTF-8 文本。证券候选采用显式市场代码及已记录证券名称。选择候选后确认作者、证券、发言归属和方向。一个发言提到多只股票时，分别录入对应股票与证据。允许保存待确认内容。首版证据摘录及观点各支持 700 字符，文本导入支持 32 KiB。

上方股票按行业横向排列。下方显示所选股票的五列观点明细。看多、看空人数按时间范围内每位作者最新一条已确认的本人观点统计。早期观点可在时间线回看，核实问题和结果可用编辑入口补录。

插件 ID 为 crs.xueqiu-watch。Core 定义观点模型与验证，Wpf 负责交互，Jobs 管理专属 SQLCipher 数据库 opinions.db。私人资料经 Windows 管理员管道访问，保存时由插件确认修订号并按请求标识去重。正文与证据保存在插件库内，主调度库无需登记这些操作。

## Google Alerts RSS 自动追踪

第一阶段采用免费 Google Alerts 做文章发现，不自建搜索引擎、不使用 RSSHub，也不让 CRS 自动登录 Google。每位作者单独创建一个 Google Alert：

1. 在「观察名单」中选择作者，点击「复制搜索条件」。默认条件为 `site:xueqiu.com/{账号ID}`，可按实际收录情况调整。
2. 点击「打开 Google Alerts」，登录自己的 Google 账号并创建提醒；建议来源保持自动、语言选择中文、结果数量选择「所有结果」。
3. 在提醒的投递方式中选择 RSS，复制 Google 生成的 RSS Feed 地址。
4. 将该地址粘贴到当前作者的「Google Alerts RSS 地址」并保存。

如需通过 Mihomo 联网，可在「观察名单 → RSS 代理」填写本机 HTTP / Mixed 地址，例如 `http://127.0.0.1:7890`。Worker 从下次任务起仅对 Google Alerts RSS 使用该地址，Mihomo 按自己的规则选择节点。代理连接失败会在线索状态中显示。清空地址可恢复默认网络。

Google Alerts 是免费服务，但搜索索引覆盖和更新时间不保证完整；它不是雪球官方全量动态接口。建议先用四位大 V 进行两周试运行，观察收录率和漏报情况。RSS URL 含订阅标识，按凭据处理；CRS 将它保存在 SQLCipher 加密的观点数据库中，不应写入日志或公开。

CRS.Feed 负责通用抓取、RSS / Atom / JSON Feed 解析、ETag / Last-Modified 和资源限制；雪球 Jobs 负责作者归属校验、线索去重和存储。Google Alerts 文章链接可能经过 `google.com/url` 跳转，插件只还原并接受最终指向当前作者数字账号路径的雪球原帖。非雪球链接、其他作者链接和不符合帖子路径的结果会被忽略。

RSS 采集会保存文章标题、摘要、Feed 正文、Feed 作者、发布时间及原帖链接，供插件后续识别股票标的和多空线索。线索列表展示 RSS 标题和摘要，并对标题、摘要及 Feed 正文运行本地规则，直接显示股票候选和「看好 / 看空 / 观望」等措辞线索；从选中线索录入观点时会自动带入可用内容，再次运行规则识别。规则结果只是候选，不自动成为已确认观点；必须核对原文、作者归属、股票及上下文后再保存。首版不调用付费 AI API，避免试运行产生模型费用。

在「任务中心 → 服务计划 → 添加计划」选择「发现雪球发言线索」。建议先手动试跑，再设置北京时间 09:15。每位作者独立采集，单个来源失败不会阻断其他作者。304 仅表示 Feed 未变化；Feed 返回空列表不代表作者没有发言，也不能证明覆盖完整。失败、限流和访问受限可在任务记录和作者状态中查看。原帖线索与已确认投资观点分开存储。方案与使用边界见 [雪球观点追踪方案](../../../docs/modules/XUEQIU_OPINION_TRACKING_DESIGN.md)。


主界面「发言线索」入口显示已保存的线索数量。核对原帖后，可选择「从选中线索录入观点」，自动带入作者和链接。填写原帖发言时间、归属和观点后可以保存。分配了股票的观点会按当前筛选条件显示，标的未确认的观点可到「待认领股票」查看。

在线索中选择「查看 / 补录正文」可粘贴完整原帖或导入 UTF-8 文本，最大 256 KiB。核实原帖和北京时间后保存，列表显示「全文 · 手工补录」。从这条线索录入观点时，编辑器从完整文本提取股票候选，可选取原文段落作为证据。个股详情选中观点后点击「原帖正文」，可查看它关联的正文版本。后来修订全文时，既有观点继续引用保存时的版本。

本地验证使用 [Worker 开发打包脚本](../../../tests/Publish-BackgroundService.ps1) 生成候选，再用 CRS.Tests.Background --xueqiu-private-data <候选包目录> 检查真实管道、加密数据库、作者配置和观点统计。桌面加载使用 CRS.Tests.PluginHost --load-probe。
