# 雪球观点追踪

从 **扩展工具 → 雪球观点追踪** 打开。需使用包含本插件的桌面与 Worker 版本，并以 Windows 管理员权限打开 CRS。首次运行预置八个观察账号，账号名称、备注、启用状态和移除均可在观察名单中设置。

「录入 / 导入资料」支持手工笔记和有权处理的 UTF-8 文本。证券候选采用显式市场代码及已记录证券名称。选择候选后确认作者、证券、发言归属和方向。一个发言提到多只股票时，分别录入对应股票与证据。允许保存待确认内容。首版证据摘录及观点各支持 700 字符，文本导入支持 32 KiB。

上方股票按行业横向排列。下方显示所选股票的五列观点明细。看多、看空人数按时间范围内每位作者最新一条已确认的本人观点统计。早期观点可在时间线回看，核实问题和结果可用编辑入口补录。

插件 ID 为 crs.xueqiu-watch。Core 定义观点模型与验证，Wpf 负责交互，Jobs 管理专属 SQLCipher 数据库 opinions.db。私人资料经 Windows 管理员管道访问，保存时由插件确认修订号并按请求标识去重。正文与证据保存在插件库内，主调度库无需登记这些操作。

## RSS 自动追踪

不再使用 Google Alerts、Google RSS 或浏览器自动登录。请在「观察名单」中为每位作者配置独立的 RSS / Atom / JSON Feed 地址。可以粘贴有权使用的来源，也可以用「填入 RSSHub 示例」生成 https://rsshub.app/xueqiu/user/{账号ID}。公共 RSSHub 属于第三方服务；生产环境优先考虑自建实例或已获得授权的数据源。

CRS.Feed 负责通用抓取、解析、条件请求和资源限制；雪球 Jobs 负责作者归属校验、线索去重和 SQLCipher 存储。旧版 Google Alerts 地址会在数据库升级时丢弃，已有历史线索保留，旧覆盖状态清空。为作者配置新 RSS 后才会恢复自动采集。

在「任务中心 → 服务计划 → 添加计划」选择「发现雪球发言线索」。建议时间为北京时间 09:15，启用前可以先保存并手动试跑。每个作者独立采集，按作者账号与规范雪球原帖链接去重。首次发现时间为 CRS 的记录时间。Feed 返回空列表不代表作者没有发言，也不能证明覆盖完整；失败、限流和访问受限可在任务记录和作者状态中查看。原帖观点与自动发现的线索分开存储。方案与使用边界见 [雪球观点追踪方案](../../../docs/modules/XUEQIU_OPINION_TRACKING_DESIGN.md)。

主界面「发言线索」入口显示已保存的线索数量。核对原帖后，可选择「从选中线索录入观点」，自动带入作者和链接。填写原帖发言时间、归属和观点后可以保存。分配了股票的观点会按当前筛选条件显示，标的未确认的观点可到「待认领股票」查看。

本地验证使用 [Worker 开发打包脚本](../../../tests/Publish-BackgroundService.ps1) 生成候选，再用 CRS.Tests.Background --xueqiu-private-data <候选包目录> 检查真实管道、加密数据库、作者配置和观点统计。桌面加载使用 CRS.Tests.PluginHost --load-probe。
