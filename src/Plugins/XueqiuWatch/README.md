# 雪球观点追踪

从 **扩展工具 → 雪球观点追踪** 打开。需使用包含本插件的桌面与 Worker 版本，并以 Windows 管理员权限打开 CRS。首次运行预置九个观察账号，其中包括管我财、学知利行、达人知命和股市小民a，账号名称、备注、启用状态和移除均可在观察名单中设置。

正文或线索中的雪球股票标签（如 `$融捷股份(SZ002192)$`）会自动带入名称和代码，并在各股票下显示原帖提及。同一篇文章可以关联多只股票，重复标签在同一股票下只计一次。可在「发言线索」选择对应股票并核对观点。发言归属、方向和证据按股票分别核对。证据摘录及观点各支持 700 字符。

股票区按「A 股」「港股」「美股」排列三个标签页，默认打开 A 股（沪市、深市和北交所）。各标签页独立翻页。通过「明细视图」切换原帖提及和已核对观点，明细每页最多显示 20 条。原帖提及按作者汇总当前筛选范围内的帖子篇数，双击内容可打开雪球原帖。看多、看空人数按时间范围内每位作者最新一条已确认的本人观点统计。早期观点可在时间线回看，核实问题和结果可用编辑入口补录。

点击股票区右上角的眼睛可按 A 股、港股、美股查看完整股票清单。行末眼睛表示股票当前可见，带斜杠的眼睛表示已隐藏。点击行末图标可切换状态。右键股票也可快速隐藏。设置按市场与代码保存，刷新和重启后继续生效。

插件 ID 为 crs.xueqiu-watch。Core 定义观点模型与验证，Wpf 负责交互，Jobs 管理专属 SQLCipher 数据库 opinions.db。私人资料经 Windows 管理员管道访问，保存时由插件确认修订号并按请求标识去重。正文与证据保存在插件库内，主调度库无需登记这些操作。

## 作者动态采集

在「观察名单」添加并启用雪球主页链接或数字账号 ID，Worker 会通过匿名 API 回补最近 30 天的公开动态。回补分批翻页，重启或限流后按已核对的重叠帖子续查。采集同时按作者和帖子 ID 去重，正文继续分批核对。可在「发言线索」的作者状态中查看待回补进度。若尚无采集计划，桌面会为首次回补创建暂停的计划并手动触发一次。全天候定期跟踪可在任务中心启用计划。

日常增量回查从上次完整检查前 12 小时开始，每位作者每轮最多读取八页。读取中断或触及增量页数上限时，已返回的有效线索仍会保存，下轮沿用原有基准。

作者动态读取失败或未读全时，任务改查该作者已绑定的备用 RSS。需要添加或维护备用订阅时，从「观察名单 → 更多 → 备用 RSS」同步，或打开 Google 登录。同步会复用同一查询的提醒，并核对待移除作者的托管订阅。双击已绑定的作者可查看备用地址。Google RSS 覆盖取决于搜索索引，订阅地址保存在 SQLCipher 数据库内。

在「任务中心」为该任务选择直连或已配置的 Mihomo 节点，定时和手动执行均沿用任务设置。旧版 RSS 代理仅用于尚未保存新版线路的 Google Alerts 订阅。

任务另用详情 API 核对正文，每轮最多 20 条。核对通过后标记「全文 · 雪球原帖 API」，正文缺失或疑似截断时保留线索片段。动态与详情共享限流退避，HTTP 429 按响应的重试时间暂停，HTTP 567 暂停六小时。备用 RSS 可在 API 暂停期间继续采集。

可在作者设置中填写「获授权的全文 Feed 地址」，作为已有授权的供稿来源。支持包含原帖链接、发布时间及纯文本正文的 [JSON Feed](https://www.jsonfeed.org/version/1.1/)（`content_text`）或 Atom（内联纯文本 `content`）。已归档的正文会跳过后续自动采集。

主界面「发言线索」入口显示已保存的线索数量。核对原帖后，可选择「从选中线索录入观点」，自动带入作者和链接。填写原帖发言时间、归属和观点后可以保存。分配了股票的观点会按当前筛选条件显示，标的未确认的观点可到「待认领股票」查看。

在线索中选择「查看正文」可读已保存的原帖全文及来源，亦可打开雪球原帖。原有的手工正文及历史版本可以继续查看。从线索录入观点时，编辑器从完整文本提取股票候选，可选取原文段落作为证据。个股详情选中观点后点击「原帖正文」，可查看它关联的版本。

本地验证使用 [Worker 开发打包脚本](../../../tests/Publish-BackgroundService.ps1) 生成候选，再用 CRS.Tests.Background --xueqiu-private-data <候选包目录> 检查真实管道、加密数据库、作者配置和观点统计。桌面加载使用 CRS.Tests.PluginHost --load-probe。
